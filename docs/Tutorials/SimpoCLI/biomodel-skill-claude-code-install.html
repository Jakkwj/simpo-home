Install BioModel Skill for Claude Code

The Claude Code version is distributed as the simpo plugin from the SIMPO Marketplace. The plugin contains all SIMPO Skills, including the complete simpo-create-biomodel workflow and its three paper-analysis references.

See the Skills overview for the complete directory and function table.

Prerequisites​

Claude Code, Git, and SimpoCLI are required. The CLI/backend will check authentication and the write scope when creation is requested:

claude --help
git --version
simpo --help

If no valid Token is saved, run simpo configure interactively when needed. Marketplace installation is managed by Claude Code and its plugin cache path is not a stable user directory. The manual fallback is ~/.claude/skills/simpo-create-biomodel. Never put the Token in a Claude prompt.

Install from the SIMPO Marketplace​

Claude Code officially supports repository Marketplaces. Run these slash commands inside an interactive Claude Code session. Add the GitHub repository using the documented owner/repo form:

/plugin marketplace add Jakkwj/simpo-home

Install the plugin:

/plugin install simpo@simpo

If Claude Code reports that a reload is required, run:

/reload-plugins

Plugin Skills are namespaced, so this Skill is invoked as /simpo:simpo-create-biomodel.

Verify​

Run this in the new or reloaded session:

/simpo:simpo-create-biomodel What does this Skill do? Do not create anything.

Installation succeeded if Claude Code explains that it analyzes a paper and prepares a reviewed Private Draft BioModel through SimpoCLI. Continue with Claude Code usage and examples.

Update​

Refresh the Marketplace, update the plugin, and reload it when prompted:

/plugin marketplace update simpo

Then open /plugin, select Installed, choose simpo@simpo, and select Update. You may instead update it from a shell with:

claude plugin update simpo@simpo

Manual fallback​

If the installed Claude Code version does not support plugins, update Claude Code. As a temporary local fallback, copy the complete repository directory plugins/simpo/skills/simpo-create-biomodel to ~/.claude/skills/simpo-create-biomodel; do not copy only SKILL.md, because the workflow needs its bundled references/ files. The fallback command is /simpo-create-biomodel, without the plugin namespace.
