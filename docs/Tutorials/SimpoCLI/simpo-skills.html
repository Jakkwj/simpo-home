SIMPO Skills Overview

This page is the directory for the AI Skills available for SIMPO. It shows what each Skill does, how to invoke it in Codex or Claude Code, where a direct installation is placed, and where to find the detailed installation and usage guides.

The Codex and Claude Code packages use the same Skill content; only the installation and invocation syntax differs.

Choose a Skill​

  • Use SimpoCLI when the task operates on existing SIMPO resources or runs a calculation. Examples include reading Project Variables, updating a Draft BioModel, or checking calculation status.
  • Use SIMPO BioModel when the task starts with a paper or explicit model specification and needs a scientifically reviewed BioModel. It asks for review before creating the Private Draft through SimpoCLI.
  • Use SIMPO DataSet when the task starts with wastewater-treatment design conditions, an existing process, or source literature and needs complete, evidence-aware, hydraulically checked DataSet tables.
  • Use SIMPO Project when one SCI paper should produce a linked BioModel, DataSet, and Project. It coordinates the two extraction workflows and adds a calibrated figure-data step for values that appear only in plots.
  • Combine the specialized Skills with SimpoCLI when the resulting BioModel or DataSet must later be inspected, updated, released, or used in a Project.

Install the Skills​

Codex​

Ask Codex's built-in Skill Installer to install the required repository path:

Use $skill-installer to install this Skill from:
https://github.com/Jakkwj/simpo-home/tree/master/plugins/simpo/skills/simpo

For the BioModel Skill, replace the final path with plugins/simpo/skills/simpo-create-biomodel; for the DataSet Skill, use plugins/simpo/skills/simpo-create-dataset; for the paper workflow, use plugins/simpo/skills/simpo-create-project. Manual installation copies the complete directory, including SKILL.md and references/, to the matching $CODEX_HOME/skills/<skill-name> directory. Include scripts/ when present. For the Project workflow, install all four Skills: it reuses the BioModel and DataSet workflows and the SimpoCLI command reference. Restart Codex after installation.

Claude Code​

The recommended installation installs the single simpo plugin, which contains all current Skills:

/plugin marketplace add Jakkwj/simpo-home
/plugin install simpo@simpo

After a reload, use the namespaced commands shown in the table. If the Claude Code version cannot install plugins, copy each complete Skill directory to its matching ~/.claude/skills/<skill-name> fallback path.
