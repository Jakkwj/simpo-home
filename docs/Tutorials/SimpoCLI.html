SimpoCLI command-line guide

SimpoCLI is the command-line interface for the SIMPO OpenAPI. It manages the complete Draft, synchronization, and Release lifecycle for BioModels, DataSets, and Projects; reads and updates Project Variables; prepares calculations; starts the locally installed SimpoClient; monitors or stops calculations; and reads large stored results in bounded pages. Its terminal command is the short, lowercase simpo.

This page is the complete SimpoCLI command index. Each command also has its own page in the collapsible SimpoCLI section. Every command supports --help when syntax is unclear or a usage error occurs. Ordinary operations can run directly; the backend checks permissions.

For AI assistant integrations, see the SIMPO Skills overview for the complete Codex and Claude Code directory, invocation names, installation paths, and detailed guides.

SkillPurpose
simpoOperate the CLI and read its JSON results.
simpo-create-biomodelBuild a model from a paper or explicit user-defined equations.
simpo-create-datasetBuild a DataSet from design inputs, source tables, or calibrated figure data.
simpo-create-projectReuse both extraction workflows to create linked resources and test paper reproduction.

These are assistant Skills, not additional terminal subcommands. Use $simpo-create-project in Codex or /simpo:simpo-create-project in the Claude Code plugin.

Prerequisites​

  • A SIMPO account and an OpenAPI Token created on the Dashboard's API Tokens page.
  • The minimum Token scope required by the command:
    • read: list and read owned BioModels, DataSets, and Projects, read Project Variable fields, and retrieve stored calculation results;
    • write: create, update, synchronize, or release BioModels, DataSets, and Projects, and update a Variable field in a version 0 Draft Project;
    • calculate: prepare, inspect, or stop a calculation.
  • The calculate command additionally requires the matching platform version of SimpoClient on the same computer.

Download and install​

SimpoCLI is independent from SimpoClient, but the calculate command starts SimpoClient to perform the actual local calculation. Install both applications if this computer will run calculations.

SimpoClient​

  • Windows: download the Windows installer.
  • Linux: download the Debian package.

SimpoCLI​

  • Windows
  • Linux

Download: download the Windows x64 installer.

Install: double-click the installer, or run the downloaded file from CMD or PowerShell:

.\SimpoCLI_VERSION_windows_x64.exe

VERSION is the version number in the downloaded filename. After installation, open a new CMD or PowerShell window so the updated PATH is available.

Verify:

simpo --version
simpo --help

Uninstall: remove SimpoCLI from Settings → Apps → Installed apps, or run:

C:\Program Files\SimpoCLI\unins000.exe

Uninstallation removes the program and its PATH entry, but preserves %APPDATA%\SimpoCLI\SIMPO_API_TOKEN.json. To remove the saved Token, run simpo logout before uninstalling, or manually delete the user data directory afterwards.

Ubuntu 20 and later are supported.

Download: download the amd64 Debian package.

Install: run this command in the download directory:

sudo apt install ./SimpoCLI_VERSION_amd64.deb

VERSION is the version number in the downloaded filename. To install with dpkg instead, run:

sudo dpkg -i SimpoCLI_VERSION_amd64.deb
sudo apt install -f

Verify:

simpo --version
simpo --help

Uninstall:

sudo apt remove simpo-cli

You can also run sudo dpkg -r simpo-cli. Standard uninstallation removes the program but preserves ~/.SimpoCLI/SIMPO_API_TOKEN.json. To remove the saved Token, run simpo logout first, or manually delete ~/.SimpoCLI after uninstalling.

Obtain your personal API Token​

  1. Sign in to the SIMPO Dashboard.
  2. Open Account → API Tokens.
  3. Select Create Token.
  4. Enter a recognizable name, choose an expiry from 1 to 365 days, and grant only the scopes you need:
    • read for all get-* commands, including paginated get-calculation-result retrieval;
    • write for BioModel, DataSet, and Project create/update/sync/release commands, and set-project-variable;
    • calculate for calculation preparation, status, and stop commands.
  5. Select Create Token, then immediately copy the complete Token from the Token Created dialog.
Copy the complete Token now

For security, the complete Token is displayed only once. The Token list later shows only tokenPrefix, which cannot authenticate API requests. If the secret is lost, revoke that Token and create a new one. Do not use a Dashboard login JWT as an OpenAPI Token.

Configure and verify the Token​

Save the copied personal Token and verify it before accessing a Project:

simpo configure
simpo me

To remove only the saved API Token while keeping the CLI data directory, run:

simpo logout

Token lookup order is:

  1. the command's --api-token option;
  2. the SIMPO_API_TOKEN environment variable;
  3. the per-user SIMPO_API_TOKEN.json file.

The saved file is ~/.SimpoCLI/SIMPO_API_TOKEN.json on Linux and %APPDATA%\SimpoCLI\SIMPO_API_TOKEN.json on Windows. Protect this file; it contains the complete secret Token.

For the complete configuration procedure, see configure.

Command reference​

Each resource follows the same basic rule: edit a version 0 Draft, use a published Release as an immutable snapshot, and use sync-* to copy a Release back to its Draft. The update pages describe dependent Project rebuilding and stale calculation results where those rules apply. Use the tables below as the complete command directory.

Token​

Output contract​

  • Successful results are formatted JSON on stdout.
  • Progress and errors are written to stderr.
  • Exit code 0 means success; a non-zero code means the command failed.
  • HTTP errors contain the status code and a safe backend message. 401 usually indicates an invalid, expired, revoked, or environment-mismatched Token; 403 indicates a missing scope.

This makes stdout safe to parse in automation:

result="$(simpo get-project-variables 706)" || exit $?
printf '%s\n' "$result"

Use --base-url only for a one-command development override, for example:

simpo me --base-url http://127.0.0.1:8888

The Token must belong to the selected backend environment.
