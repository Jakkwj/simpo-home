SIMPO 1.4.0 发布：SCE-UA 算法

2026年10月5日 · 阅读需 4 分钟

SIMPO 由中山大学环境科学与工程学院江峰教授团队发起，是一个面向污水处理数学模拟的无代码智能建模与共享平台。本次更新的具体内容请查看：SIMPO 1.4.0 更新日志。

本次更新从计算引擎、资源管理、结果可视化和账户体验等方面进行了全面升级。其中，Estimation 计算引擎正式新增 SCE-UA 算法，为参数优化提供更强大的选择。

新增功能​

SCE-UA 算法：参数估计能力再升级​

Estimation 计算引擎现已支持 SCE-UA（Shuffled Complex Evolution - University of Arizona） 算法。SCE-UA 是一种基于群体的全局优化算法：它会同时演化多组候选参数，这些参数组称为 Complex，并定期进行混洗，让不同参数组共享有效的搜索信息。

当然，和其他优化算法一样，单次成功运行并不能证明已经找到全局最优解。对于重要研究，建议比较不同的初始化方法和超参数下的结果。

经过测试，SCE-UA 比 GA 算法通常有更快地计算速度和求解精度。

更多的初始化样本方法​

Uncertainty 和 Estimation 现在支持以下四种初始样本生成方法：

方法简单说明Seed 行为
LHS拉丁超立方抽样，将每个变量的取值范围划分为多个区间，并在每个区间中选取一个样本，以较少的样本数量实现较均匀的范围覆盖。开启 Fixed Initial Seed 后可以复现。
Sobol确定性的低差异序列，使样本在多维空间中更加均匀地分布。本身是确定性的，不使用 seed。
Sobol (Scrambled)对 Sobol 序列进行扰动，在保留低差异覆盖特性的同时，为不同运行引入可控的变化。开启 Fixed Initial Seed 后可以复现。
Uniform在每个变量范围内独立均匀地随机取样，方法简单，但随机样本可能出现聚集或空缺。开启 Fixed Initial Seed 后可以复现。

如果重视较均匀且可复现的覆盖，可以选择 LHS 或 Sobol (Scrambled)；如果希望使用确定性序列，可以选择 Sobol；如果需要简单的随机基线，可以选择 Uniform。

Seed：让初始化样本可复现​

开启 Fixed Initial Seed，并填写 1 到 4294967295 之间的整数。只要 Project 内容、初始化方法、样本数量或初始种群大小以及 seed 保持一致，SIMPO 就会生成相同的初始样本，便于进行结果对比和问题排查。

关闭 Fixed Initial Seed 后，每次运行都会生成不同的随机初始化结果。

注意，Seed 主要控制初始化阶段，如果需要复现完整计算，还需要保持其他计算设置。

此外，Sobol 方法本身是确定性的，不受 seed 控制。

BioModel、DataSet 和 Project 支持分组​

现在，BioModel、DataSet 和 Project 列表均支持分组功能，您可以按照主题、实验或项目阶段进行分类，让资源查找和维护更加高效。

PointSettlingTank 结果图表更加直观​

在 PointSettlingTank 的 Simulation 和 Optimum 结果图中，Outlet 和 Blanket 现已合并展示，相关结果对比更加清晰。

体验优化​

  • 支持修改用户名： 您现在可以随时修改用户名。
  • 账户管理统一： 修改密码和修改邮箱功能已合并至 Account 页面，操作路径更加简洁统一。

问题修复​

  • 修复了 Inflow 和 Flow 时间轴不一致时的计算问题。
  • 修正了 BioModel.Rate 中 If 函数的判断逻辑，现在可以正确提取条件中的公因数。
  • 修复了 BioModel 保存时可溶性物质未按规范置于前方的问题。
  • 修复了修改 BioModel、DataSet 或 Project 内容时同时修改名称，其他修改内容无法正确保存的问题。
  • DataSet 现在可以准确导入和导出超大布局。
  • 绘制和保存 Estimation 结果时，现在可以准确显示转换后的时间单位。
  • 修复了表格无法使用 Ctrl 和 Shift 快捷键进行多选的问题。
  • 修复了部分用户注册时无法收到注册确认邮件的问题。
