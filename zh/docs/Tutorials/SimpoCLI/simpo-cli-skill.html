SimpoCLI Skill

SimpoCLI Skill 是供 AI 编码助手按需读取的操作指南。它让助手先识别当前安装的 simpo 接口，再选择正确命令、保护 API Token、检查所需 scope、审查会改变状态的 操作、解析 JSON 结果，并处理结果不确定的失败。

是的，它可以减少每次对话中重复输入的 token。Skill 采用渐进加载：

  1. 平时只提供很短的名称和描述，用于判断是否应触发；
  2. 触发后才加载核心 SKILL.md；
  3. 然后只读取当前任务所需的命令组资料，例如 BioModel 或 Calculation。

因此不需要在每次对话中粘贴完整 CLI 说明书。调用 Skill 本身仍会占用一些上下文， 而且它会主动检查 simpo COMMAND --help，因为实际安装版本才是最终依据。它减少的 是重复且与当前任务无关的输入，并不是完全不消耗 token。

覆盖范围​

当前 Skill 源码同时供 Codex 和 Claude Code 使用。Codex 调用名为 $simpo， Claude Code 插件调用名为 /simpo:simpo。它包含：

  • Token 配置、身份、scope、退出登录和 JSON 自动化；
  • BioModel 新建、列表、读取、更新、同步和发布；
  • DataSet 列表和读取；
  • Project 列表及 Project Variable 读取和更新；
  • 计算准备、引擎选择、状态查询和停止。

按当前开发版 CLI 源码核对，Skill 已覆盖全部 17 个公开顶层命令： configure、me、logout、create-biomodel、update-biomodel、 sync-biomodel、release-biomodel、get-biomodels、get-biomodel、 get-datasets、get-dataset、get-projects、get-project-variables、 set-project-variable、calculate、calculation-status 和 stop-calculation。

这里指的是 Skill 的覆盖范围，不代表旧版已安装程序一定提供全部 17 个命令。Skill 会 始终检查当前 simpo --help；所需命令不存在时，会要求先升级 SimpoCLI。

此 Skill 负责操作 SimpoCLI，不包含 SimpoCLI 安装包或 API Token。它也不替代专用的 BioModel Skill；后者用于分析研究论文并推导模型表格。

安全边界​

  • 以当前安装的 simpo --help 和 simpo COMMAND --help 为准。
  • Token 通过 simpo configure 的隐藏输入配置，不能粘贴到 AI 对话中。
  • 只询问说明不会授权执行写操作。
  • Public 发布、开始/停止计算以及其他重要写操作需要先确认目标和影响。
  • 写操作超时后先查询当前状态，再决定是否重试，避免重复创建、发布或计算。

Codex 请参阅安装和使用方法； Claude Code 请参阅安装和 使用方法。
