编辑

BioModel 中可编辑的内容包括 Detail，Version 和 Profile。

Detail​

BioModel 的 Detail 页面包含了 Components，Parameters，Compositions，Ionization 和 Processes 等组件。

1. Components​

Components 是模型的组分，是模型模拟计算的主要对象，通常包括各种溶解态（Soluble）和颗粒态（Particulate）的基质和微生物。

  • Components 组件弹窗中可以进行查看和编辑操作：
    • 编辑操作包括新建，复制，删除和移动排序。
    • 可以通过 ctrl/shift + 鼠标左键选择多行进行批量操作。
  • 具体内容包括：
    • Symbol 只能由英文字母，数字和下划线（下划线不能连续）组成：
      • Soluble 组分必须以“S_”为前缀进行命名，如溶解氧（DO）应命名为 S_O2。
      • Particulate 组分必须以“X_”为前缀进行命名，如普通异养菌（OHO）应命名为 X_OHO。
      • 保存时，会自动把 Soluble 组分放在 Particulate 组分的前面。
      • Soluble 组分 和 Particulate 组分在沉淀行为上有不同的特性。
    • Unit:
      • Unit 不可为空。
      • Unit 会显示在计算结果的图片中。
    • Name 可以为空。
    • Description 可以为空。

2. Parameters​

Parameters 是模型中使用的参数，包括化学计量学参数（Stoichoimetry）和动力学参数（Kinetic），是调参 （Parameter Estimation）的主要对象。

  • Parameters 组件弹窗中可以进行查看和编辑操作：
    • 编辑操作包括新建，复制，删除和移动排序。
    • 可以通过 ctrl/shift + 鼠标左键选择多行进行批量操作。
  • 具体内容包括：
    • Symbol 只能由英文字母，数字和下划线（下划线不能连续）组成，且必须以字母为开头。
    • Unit：
      • 不可为空。
      • 如果参数是动力学参数，其单位必须以：/d, d-1, /day, day-1, 1/d, 1/day, /h, h-1, /hour, hour-1, 1/h, 1/hour, /m, m-1, /minute, minute-1, 1/m, 1/minute, /s, s-1, /second, second-1, 1/s or 1/second 为结尾，这样才能保证整个计算过程中时间单位的统一。
      • 比如某动力学参数 u_max 的默认值为 10 /d， 则可以输入：
        • DefaultValue 为 10，Unit 为 /d（或者 d-1, /day, day-1, 1/d, 1/day）。
        • 或者 DefaultValue 为 10/24，Unit 为 /h（或者 h-1, /hour, hour-1, 1/h, 1/hour）。
        • 或者 DefaultValue 为 10/24/60，Unit 为 /m（或者 m-1, /minute, minute-1, 1/m, 1/minute）。
        • 或者 DefaultValue 为 10/24/60/60，Unit 为 /s（或者 s-1, /second, second-1, 1/s, 1/second）。
        • 动力学参数的单位以这些为结尾即，即 /d 与 mgCOD/d 效果相同。
    • DefaultValue：
      • 不可为空。新建 Project 时 Solution.Variable 的 Value 会使用这个值。
      • 注意：计算时，以 Project.Solution 中的值为准。
    • LowerBound：
      • 非空时，新建 Project 时 Solution.Variable 的 LowerBound 会使用这个值。
      • 为空时，新建 Project 时 Solution.Variable 的 LowerBound 会默认设置为 Value * 0.1。
      • 注意：计算时，以 Project.Solution 中的值为准。
    • UpperBound：
      • 非空时，新建 Project 时 Solution.Variable 的 UpperBound： 会使用这个值。
      • 为空时，新建 Project 时 Solution.Variable 的 UpperBound： 会默认设置为 Value * 1.1。
      • 注意：计算时，以 Project.Solution 中的值为准。
    • Name 可以为空。
    • Description 可以为空。

3. Compositions​

Compositions 用于检查模型的各物质平衡，包括 ThOD、N、P、S、Charge 和 TSS 共 6 种平衡。它不是另一组动力学过程，而是为每个 Component 指定“每单位组分含有多少平衡物质”的系数矩阵。

3.1 计算方式​

设 Processes 矩阵中 Process p 对 Component i 的化学计量系数为 ν(i,p)，Compositions 矩阵中平衡 b 对 Component i 的组成系数为 c(b,i)，则该 Process 的平衡结果为：

Balance⁡b,p=∑icb,i νi,p\operatorname{Balance}_{b,p}=\sum_i c_{b,i}\,\nu_{i,p}Balanceb,p​=i∑​cb,i​νi,p​

计算时，对该 Process 的所有 Components 逐列相乘并求和；Rate 列不参与求和。结果为零表示该 Process 在所选平衡上守恒，非零表示该 Process 存在不平衡。Compositions 中的空单元按 0 处理，系数可以是常数、分数或引用 Parameters 的公式（例如 i_N_X_B）。公式会使用当前 BioModel/Project 的参数值计算。

例如，ASM2 的好氧硝化过程可写成（为了让 Balance 精确为零，4.57 应写成 64/14）：

νS_O2=−64/14−YANOYANOνS_NHx=−1YANOνS_NOx=1YANOνX_ANO=1\begin{aligned} \nu_{S\_O2} &= -\frac{64/14-Y_{ANO}}{Y_{ANO}}\\ \nu_{S\_NHx} &= -\frac{1}{Y_{ANO}}\\ \nu_{S\_NOx} &= \frac{1}{Y_{ANO}}\\ \nu_{X\_ANO} &= 1 \end{aligned}νS_O2​νS_NHx​νS_NOx​νX_ANO​​=−YANO​64/14−YANO​​=−YANO​1​=YANO​1​=1​

在 ThOD 行使用 S_O2 = -1、S_NOx = -64/14、X_ANO = 1 时，上述系数的加权和为零；若过程矩阵保留四舍五入的 4.57，则可能出现一个很小的残差。这个“组成系数向量 × 过程化学计量向量”的点积，就是 SIMPO 在 Balances 中检查的值。

3.3 S（硫）平衡的推导​

S 平衡只追踪硫元素的量，不追踪硫的氧化态。设 Component i 的质量基准中含有 m_S(i) g 硫，Component 本身对应的质量基准为 m_i g，则其 S 组成系数为：

cS,i=mS(i)mic_{S,i}=\frac{m_S(i)}{m_i}cS,i​=mi​mS​(i)​

因此，Process p 的 S 平衡仍然是同一个点积：

Balance⁡S,p=∑icS,i νi,p\operatorname{Balance}_{S,p}=\sum_i c_{S,i}\,\nu_{i,p}BalanceS,p​=i∑​cS,i​νi,p​

推导步骤是：

  1. 从 Component 的化学式确定每个分子（或经验单元）含有的硫原子数。
  2. 用硫的相对原子质量 M_S=32 计算硫的质量。
  3. 按 Component 的单位换算为 gS；如果 Component 已经使用 gS/m³，则系数直接为 1。
  4. 将该系数乘以 Processes 矩阵中的化学计量系数，并对所有 Components 求和。

例如，在引用的脱氮除硫模型中，S_S2、S_S0 和 S_SO4 若都以 gS/m³（或 mgS/L）表示，则：

cS,S_S2=cS,S_S0=cS,S_SO4=1c_{S,S\_S2}=c_{S,S\_S0}=c_{S,S\_SO4}=1cS,S_S2​=cS,S_S0​=cS,S_SO4​=1

硫化物氧化为单质硫、单质硫氧化为硫酸盐，以及硫化物直接氧化为硫酸盐时，S 行分别表现为 (-1,+1)、(-1,+1) 和 (-1,+1)，所以 S 平衡结果均为零。氧化态变化由 ThOD 或 Charge 行反映，不应在 S 行中额外乘以 2、6 或 8。

3.4 N 形态的经典 ThOD 系数​

ASM2 的 ThOD 系数以 NH4-N（氮氧化态 -3）作为参考。对于每增加 1 个氮氧化态，相当于增加 1 个电子当量；在 gN 基准下，每个电子当量对应 8/14 gO2/gN。因此，对含 1 mol N 的组分，可用下式得到相对于 NH4-N 的 ThOD 组成系数：

cThOD=−(oxidation state+3)814c_{\mathrm{ThOD}}=-\left(\mathrm{oxidation\ state}+3\right)\frac{8}{14}cThOD​=−(oxidation state+3)148​

在 ASM2 的符号约定中，较氧化的氮形态为负值；这不是说该组分本身“消耗负氧”，而是表示它相对于 NH4-N 已经携带的氧化当量。常用值如下：

3.5 建议使用分数保存经典系数​

这里的“使用分数”是保存表达式的建议，不是把所有小数机械转换成分数。 只有当论文方程、化学式/元素质量基准或明确推导能够独立确定精确值时，才允许 把报告的小数替换为分数；拟合得到的参数、经验系数或无法独立验证的小数应保持 原值。修改前应在说明中同时记录原始小数、保存的分数以及推导依据。

Processes 和 Compositions 中的系数如果来自氧化还原或元素质量换算，建议保留精确分数，避免四舍五入造成 Balance 不为零。常见的十进制值与精确分数对应如下：

3.6 在界面中检查平衡​

  • Compositions 组件弹窗中可以查看和编辑 6 种平衡；不选择某一平衡，或该行全部为空，则不进行该平衡检查。
  • 如果某个 Balance(b,p) 不为零，Balances 组件会显示对应的 Process，并在进入 BioModel 页面时弹窗警告。
  • 如果所有已启用的平衡结果均为零，Balances 组件不会显示。
  • 出现非零结果时，先把 Processes 和 Compositions 中的近似小数改成精确分数，再检查单位、符号、遗漏的 Component 以及被省略的过程。
  • 如果模型有意省略某个过程，或某个平衡并不适用于该模型，可以不启用对应平衡行；不要为了消除警告而随意修改化学计量系数。

4. Ionization​

  • Ionization 用于描述 Components 在水中的电离状态，用于 pH 计算。
  • pH 作为一个特殊的组分，不需要在 Components 中进行定义，在矩阵的 Rate 列可以直接使用 pH 进行计算。
  • pH 在 DataSet 中需要被明确地定义为一个 Target，然后在 Project Conversion 页面中将 Components 和 Target 进行转化（系数通常为1），才能明确地显示在计算结果中。
  • Ionization 组件中可以进行查看和编辑操作：
    • 编辑操作包括新建，复制，删除和移动排序。
    • 可以通过 ctrl/shift + 鼠标左键选择多行进行批量操作。
  • 具体内容包括：
    • Symbol：即 Components 的 Symbol，下拉选择。
    • Compound：确定该 Component 是 Weak/Strong Acid/Base。
    • Step：确定是电离步数 （1/2/3步），Mono/Di/Tri。
    • Ionization：确定电离方式；弱酸/弱碱使用 One Step 或 Stepwise，强酸/强碱使用 Complete。
    • Factor：转化系数，单位为 mol/mg。
    • pK1/pK2/pK3：每一步的电离常数。
    • pKw：水的电离常数，通常为 14。该值只在第一行可以编辑。
  • 按照下方表格的内容填入 Ionization 中，SIMPO 就会自动计算 pH 了。当然你还需要通过 Project Conversion 页面将 Components 和 Target 进行转化，才能明确地显示在计算结果中。

5. Processes​

  • Processes 用于描述模型中发生的各种生化过程，通过矩阵（Matrix）的方式进行描述，矩阵的行是 Processes，列是 Components（除最后一列），矩阵中的元素是各个组分在各个过程中的化学计量学参数（Stoichoimetric），最后一列是每个 Processe 的速率方程。
  • 矩阵中的元素可以留空，等同于0。

5.1 公式​

  • 目前在 Rate 列中可以使用的公式包括：
    • Max：Excel 风格 Max(value1, value2, ...): 返回最大值。
    • Min：Excel 风格 Min(value1, value2, ...): 返回最小值。
    • Ln：Excel 风格 Ln(value)：自然对数。
    • Exp：Excel 风格 Exp(value): e 的指数。
    • Log：Excel 风格 Log(value): 以10为底的对数。
    • If：Excel 风格 If(condition, value_if_true, value_if_false): 根据条件返回不同的值。
  • 乘方用 ** 表示，如 x**2 表示 x 的平方，x**0.5 表示 x 的平方根。

5.2 pH​

  • pH 作为一个特殊的组分，不需要在 Components 中进行定义，在矩阵的 Rate 列可以直接使用 pH 进行计算。

5.3 负数错误​

  • 在矩阵中，某些 Component 的系数为负数时，表示该组分在该 Process 中被消耗。
  • 此时，需要注意在 Rate 中补充该 Component 的开关项（SSKS+SS\frac{S_S}{K_S+S_S}KS​+SS​SS​​），表示该组分为0时，该 Process 的速率为0，避免出现负数错误。

6. 其它操作​

  • Temp 按钮：临时保存，保存时不会检查格式，用于快速保存，可以后续再修改格式。
  • Parse 按钮：解析保存，保存时会解析格式是否正确，格式不通过将无法保存。
  • Edit 按钮：
    • 修改 BioModel 的名称。
    • 通过上传导入 xlsx 格式模版文件进行整体内容修改。
    • 选择相关论文。
    • 添加相关描述。
  • Export 按钮：导出 xlsx 格式文件。导出后可以在 Excel 中进行修改，然后再导入 BioModel 进行整体内容修改。
  • 注意：克隆和删除操作需要在 BioModel 列表中进行。

Version​

  • 在 Version 选项卡中可以把当前的 Draft 发布为不同的版本，每个版本都有一个唯一的版本号（按数字递增）。
  • 只有在 Draft 中可以修改 Detail，版本发布后不可再次修改。
  • 发布的版本分为 Public/Private 两种：
    • Public 版本可以被其它用户克隆。
    • Private 版本只能被自己使用。
  • Sync 按钮：同步当前版本的内容到 Draft 中。

Profile​

  • Profile 选项卡中可以查看 BioModel 的基本信息。
