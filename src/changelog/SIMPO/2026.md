# 2026

## 2026-06-07

- **Fixed**
  - During **Uncertainty**/**Estimation** calculations, **NEGATIVE ERROR** will automatically exclude negative results (instead of stopping calculations as before)
  - Fixed the **NSE** calculation formula when **Measured** contains empty values
  - Fixed the unit judgment issue for **Oxygen**

- **Improved**
  - When saving a **DataSet**, **Tank** items with **BioCalculated** set to `False` will be automatically moved to the end, and this order will be synchronized to **DataSet.Measured**, **Solution.Variable**, **Solution.Weight**, and **Solution.Activator**
  - The result will now be saved as an Excel file in chunks to avoid Stack Overflow errors (Windows platform).
  - When saving the result Excel file, if a sheet name exceeds 31 characters in length, it will be truncated, and a name mapping table (**SheetMap**) will be generated.

---

## 2026-05-22

- **Fixed**
  - Fixed the plotting process to prevent packet loss during rendering.

- **Improvements**
  - Further optimization for the computation of redundant **Components**: the variable step size is now enabled only when values approach zero (instead of being always enabled as before).
  - Optimized the step size for variable concentration calculations, reducing errors at each transition point.
  - **Resolution Rate** now supports upscaling of original sampling points, allowing more convenient and precise acquisition of computed sampling results.

---

## 2026-05-10

- **Fixed**
  - Spelling error `Aera` corrected to `Area`.
  - `Pump` calculations can now be triggered correctly.

- **Improved**
  - Further improved calculation speed when the `Real-Time Plotting` option is disabled.

---

## 2026-05-08

- **Fixed**
  - The `Simulation` calculation engine now correctly performs dynamic plotting.
  - Fixed the calculation formula for the variable volume of the Point Setting Tank.

---

## 2026-05-05

- **Added**
  - `Estimation` calculation engine now includes the `RFGA` algorithm.
  - `Value` and `LowerBound` of `BioModel.Parameter`/`Solution.Variable` now support negative numbers.
  - `Solution` now supports pickle caching.

- **Improved**
  - Significant thread optimization:
    - Simulation equation solving
    - Parallel optimization for Sensitivity/Uncertainty/Estimation
    - Dynamic plotting
    - Generating result files
    - Generating running code

- **Fixed**
  - Corrected the calculation formula for variable volume (i.e., when `Constant Volume` is `False`). Now, `CAS` processes can correctly simulate `SBR` processes.

## 2026-04-09

- **Added**
  - Support for steady-state calculations.

  ## 2026-04-07

- **Added**
  The `BioModel.Matrix.Rate` calculation will now automatically extract common factors, further improving computational speed.

- **Fixed**
  -Fix incorrect saving of `dynamic_volume` in the `get_result_Sim()` function.

## 2026-04-06

- **Added**
  - `BioModel.Matrix.Rate` now supports the `If()`, `Log()`, `Ln()`, and `Exp()` functions.

  ## 2026-04-04

- **Improved**
  - The `BioMatrix.get_BioStoichoimetric()` function now uniformly initializes `stoichiometric` values to `0.0D0`, resulting in improved computational speed.

## 2026-03-31

- **Improved**
  - An alert will be issued when a Pump is connected to a Tank if DO is not marked in `DataSet.Target`.
  - An alert will be issued when a Pump is connected to a Tank if there is no conversion relationship for DO in `Solution.Conversion.Target`

## 2026-03-26

  - `DataSet.Unit` now supports units for `Area` (assuming 'Area' is a typo for 'Area') and `Height`.
  - `DataSet.Target` now supports specifying `Oxygen`.
  - `DataSet.Tank` now includes four new parameters: `DiffuserNumber`, `DiffuserDepth`, `AlphaFactor`, and `BetaFactor`.

## 2026-03-13

## 2026-02-28

- **Changed**
  - In the pickle for DataSet, Hydraulics_Partical should be changed to Hydraulics_Particulate.
  - In the source code, uniformly replace `Partical` with `Particulate`.

## 2026-02-18

- **Fixed**
  - `_get_redundant_component_no()` supplements the handling when there is only one `redundant`.

## 2026-02-16

- **Fixed**
  - Removed the uncalculable judgment condition `Grid_dt_second == 0.0D0` in `Kernel` (because `Grid_dt_second` might fall exactly on a measurement point, causing `remaining_times` to be 0), thus avoiding issues where the `Step Tolerance` setting might prevent correct calculation.

## 2026-02-01

- **Fixed**
  - When the plotting function encounters a `BrokenProcessPool` error, it will use the main process to continue plotting.
  - Fixed a rare saving error in BioModel (caused by invisible spaces in the frontend).

---

## 2026-01-02

- **Added**
  - Added support for **pH** calculation; related parameters are configured in `BioModel.Ionization`.
  - The local Real-Time Plotting window now supports switching images using the left/right mouse buttons or keyboard keys, and the aspect ratio is maintained during switching.

- **Changed**
  - **Improved Euler** will no longer be supported. Equivalent computational accuracy can be achieved (more quickly) by reducing the **Step Tolerance** of **Forward Euler**.

- **Improved**
  - Optimized the Real-Time Plotting function for reduced memory and CPU consumption.
  - Removed scientific notation from axes in locally saved **SVG** images.

- **Fixed**
  - `Inflow` Figure is now displayed correctly.
  - Fixed an issue where the last point in locally saved **SVG** images was sometimes not drawn correctly.
  - The Real-Time Plotting window now refreshes correctly.
  - The taskbar icon for the Real-Time Plotting window now displays correctly.
  - Fixed some known bugs.
