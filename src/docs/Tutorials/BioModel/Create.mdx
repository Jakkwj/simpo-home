BioModel is where you build your own biochemical models.


There are several ways to create a BioModel (choose one of the six methods below):

## <a id="way_1"></a>1. Create from Blank

Create an empty BioModel, edit it, and save it with Parse so it takes effect.
- Add new components.
- Add new parameters.
- Add new processes (in the Matrix tab).

## <a id="way_2"></a>2. Create Along with a New Project

If you do not specify a BioModel when creating a new Project, an empty BioModel will be created automatically.

## <a id="way_6"></a>6. Create from a Paper Using AI


To create a BioModel, select an AI model and upload the PDF of an SCI paper. The AI will attempt to parse the paper and generate a BioModel.
