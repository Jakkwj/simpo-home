# `get-dataset`: read one DataSet

Read the complete DataSet model tables and metadata for one Draft or Release
owned by the current API Token user.

## Requirements

- Token scope: `read`
- The DataSet must belong to the Token user.
- `DATASET_ID` may identify either a version `0` Draft or a version `> 0` Release.
- A missing or unauthorized ID returns HTTP `404`.

## Syntax

```text
simpo get-dataset DATASET_ID [OPTIONS]
```

The `DATASET_ID` is the database ID returned by [`get-datasets`](./get-datasets)
or another trusted API response.

## Options

| Option | Default | Meaning |
| --- | --- | --- |
| `DATASET_ID` | required | DataSet database ID |
| `--timeout SECONDS` | `10.0` | Maximum time for the HTTP request |
| `--api-token TOKEN` | configured Token | Complete Token override |
| `--base-url URL` | packaged environment URL | Backend override for this request |

The response includes `detail`, which can contain the DataSet tables such as
`Unit`, `Target`, `Tank`, `Pump`, `Measured`, `Inflow`, `Flow`, `Connection`,
and `JointGraphJson` when present. It also includes the saved name lists,
units, parsed-state flag, counts, and version metadata.

The response deliberately excludes the internal `pickle`, `share_url`,
`shareable`, and `cloneable` fields. These are implementation or sharing
credentials, not part of the OpenAPI DataSet read contract.
