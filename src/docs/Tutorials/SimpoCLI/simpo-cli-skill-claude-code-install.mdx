# Install SimpoCLI Skill for Claude Code

## Install and update with SimpoCLI

These commands require **SimpoCLI 0.1.8 or later**. Download and install a newer
CLI once if your current version does not have them.

```bash
simpo skills install simpo --target claude
simpo skills update simpo --target claude --check
simpo skills update simpo --target claude
```

Project installs its three dependencies automatically. Omit the Skill name to
install all four or update installed Skills. All four share a version such as
`0.1.8-skills.1`; the revision can advance independently of the CLI. Start a new
assistant session afterwards. Existing manual installations and local changes
are protected; `--force` backs them up before replacement and returns the backup
location.

This installs personal-directory Skills, invoked as `/simpo`,
`/simpo-create-project`, etc. If you installed the Marketplace plugin below,
keep using Claude's plugin update manager. The CLI refuses duplicate local
installation and never edits plugin caches. Plugin invocations retain the
`/simpo:simpo` namespace.

The `simpo` Claude Code plugin packages the same `simpo` Skill and references
used by the direct Codex Skill installation. It routes SIMPO work through the
installed SimpoCLI and does not contain an API Token.

See the [Skills overview](./simpo-skills) for all Skills, invocation names, and
installation directories.

## Prerequisites

Claude Code and SimpoCLI are required:

```text
claude --help
simpo --version
simpo --help
```

Configure a Token interactively when a command needs authentication:

```text
simpo configure
```

Never paste the Token into a Claude prompt.

The Marketplace installation is managed by Claude Code and its plugin cache
path is not a stable user directory. If plugins are unavailable, the manual
fallback directory is `~/.claude/skills/simpo`.

## Install from the SIMPO Marketplace

Claude Code officially supports repository Marketplaces. Run these slash
commands inside an interactive Claude Code session. Add the GitHub repository
using the documented `owner/repo` form:

```text
/plugin marketplace add Jakkwj/simpo-home
```

Install the plugin:

```text
/plugin install simpo@simpo
```

Reload plugins if Claude Code requests it:

```text
/reload-plugins
```

The namespaced Skill command is `/simpo:simpo`.

## Verify

Run this in a new or reloaded session:

```text
/simpo:simpo What does this Skill do? Do not change anything.
```

The response should explain direct SimpoCLI operation, safe SIMPO resource
operations, and JSON result verification. Continue with
[Claude Code usage and examples](./simpo-cli-skill-claude-code-usage).

## Update

Refresh the Marketplace and update the plugin:

```text
/plugin marketplace update simpo
```

Then open `/plugin`, select **Installed**, choose `simpo@simpo`, and select
**Update**. Reload plugins if prompted.

## Manual fallback

If the installed Claude Code does not support plugins, update it first. As a
temporary local fallback, copy the complete
`plugins/simpo/skills/simpo` directory to
`~/.claude/skills/simpo`; do not copy only `SKILL.md`, because the workflow
needs its `references/` files. The fallback command is `/simpo` without the
plugin namespace.
