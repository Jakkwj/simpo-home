# `get-project`: read Project detail

Read one owned Draft or Release Project. Token scope: `read`.

```text
simpo get-project PROJECT_ID
```

The response contains the owned Project metadata, Solution `detail`, referenced
BioModel and DataSet IDs, and result metadata. Large calculation data is read
separately with [`get-calculation-result`](./get-calculation-result).

`PROJECT_ID` may identify either a version `0` Draft or a version `> 0` Release.

The backend returns an error when the Project does not exist or is not owned by
the current Token user.

Options include `--timeout SECONDS` (default `10.0`), `--api-token TOKEN`, and
`--base-url URL`.
