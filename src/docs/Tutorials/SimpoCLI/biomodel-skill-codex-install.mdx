# Install BioModel Skill for Codex

Install this Skill directly from the repository into Codex's Skill directory.

See the [Skills overview](./simpo-skills) for the complete Skill directory and
function table.

## Prerequisites

Codex and SimpoCLI are required. The CLI/backend will check authentication and
the `write` scope when the creation command is run:

```text
codex --help
simpo --help
```

If no valid Token is saved, run `simpo configure` interactively when needed.
The default Skill directory is `~/.codex/skills/simpo-create-biomodel`; with
`CODEX_HOME` set, use `$CODEX_HOME/skills/simpo-create-biomodel`.

## Install from this repository

Recommended:

```text
Use $skill-installer to install this Skill from:
https://github.com/Jakkwj/simpo-home/tree/master/plugins/simpo/skills/simpo-create-biomodel
```

Manual fallback:

```bash
mkdir -p "${CODEX_HOME:-$HOME/.codex}/skills"
cp -R plugins/simpo/skills/simpo-create-biomodel \
  "${CODEX_HOME:-$HOME/.codex}/skills/simpo-create-biomodel"
```

Keep the `references/` directory with `SKILL.md`, then start a new Codex
session.

## Verify

Ask in the new session:

```text
What does $simpo-create-biomodel do?
```

Installation succeeded if Codex explains that it analyzes a paper and creates a
Private Draft BioModel through SimpoCLI. Continue with
[Codex usage and examples](./biomodel-skill-codex-usage).

## Update

The Skill Installer does not overwrite an existing Skill. Back up or remove the
installed `$CODEX_HOME/skills/simpo-create-biomodel` directory, install the
latest GitHub copy, and start a new Codex session.
