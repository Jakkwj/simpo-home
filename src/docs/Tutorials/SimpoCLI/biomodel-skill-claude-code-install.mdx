# Install BioModel Skill for Claude Code

## Install and update with SimpoCLI

These commands require **SimpoCLI 0.1.8 or later**. Download and install a newer
CLI once if your current version does not have them.

```bash
simpo skills install simpo-create-biomodel --target claude
simpo skills update simpo-create-biomodel --target claude --check
simpo skills update simpo-create-biomodel --target claude
```

Project installs its three dependencies automatically. Omit the Skill name to
install all four or update installed Skills. All four share a version such as
`0.1.8-skills.1`; the revision can advance independently of the CLI. Start a new
assistant session afterwards. Existing manual installations and local changes
are protected; `--force` backs them up before replacement and returns the backup
location.

This installs personal-directory Skills, invoked as `/simpo`,
`/simpo-create-project`, etc. If you installed the Marketplace plugin below,
keep using Claude's plugin update manager. The CLI refuses duplicate local
installation and never edits plugin caches. Plugin invocations retain the
`/simpo:simpo` namespace.

The Claude Code version is distributed as the `simpo` plugin from the SIMPO
Marketplace. The plugin contains all SIMPO Skills, including the complete
`simpo-create-biomodel` workflow and its three paper-analysis references.

See the [Skills overview](./simpo-skills) for the complete directory and
function table.

## Prerequisites

Claude Code, Git, and SimpoCLI are required. The CLI/backend will check
authentication and the `write` scope when creation is requested:

```text
claude --help
git --version
simpo --help
```

If no valid Token is saved, run `simpo configure` interactively when needed.
Marketplace installation is managed by Claude Code and its plugin cache path is
not a stable user directory. The manual fallback is
`~/.claude/skills/simpo-create-biomodel`. Never put the Token in a Claude prompt.

## Install from the SIMPO Marketplace

Claude Code officially supports repository Marketplaces. Run these slash
commands inside an interactive Claude Code session. Add the GitHub repository
using the documented `owner/repo` form:

```text
/plugin marketplace add Jakkwj/simpo-home
```

Install the plugin:

```text
/plugin install simpo@simpo
```

If Claude Code reports that a reload is required, run:

```text
/reload-plugins
```

Plugin Skills are namespaced, so this Skill is invoked as
`/simpo:simpo-create-biomodel`.

## Verify

Run this in the new or reloaded session:

```text
/simpo:simpo-create-biomodel What does this Skill do? Do not create anything.
```

Installation succeeded if Claude Code explains that it analyzes a paper and
prepares a reviewed Private Draft BioModel through SimpoCLI. Continue with
[Claude Code usage and examples](./biomodel-skill-claude-code-usage).

## Update

Refresh the Marketplace, update the plugin, and reload it when prompted:

```text
/plugin marketplace update simpo
```

Then open `/plugin`, select **Installed**, choose `simpo@simpo`, and
select **Update**. You may instead update it from a shell with:

```text
claude plugin update simpo@simpo
```

## Manual fallback

If the installed Claude Code version does not support plugins, update Claude
Code. As a temporary local fallback, copy the complete repository directory
`plugins/simpo/skills/simpo-create-biomodel` to
`~/.claude/skills/simpo-create-biomodel`; do not copy only `SKILL.md`, because the
workflow needs its bundled `references/` files. The fallback command is
`/simpo-create-biomodel`, without the plugin namespace.
