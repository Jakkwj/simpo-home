# Install BioModel Skill for Claude Code

The Claude Code version is distributed as the `simpo` plugin from the SIMPO
Marketplace. The plugin contains both SIMPO Skills, including the complete
`simpo-create-biomodel` workflow and its three paper-analysis references.

## Prerequisites

Verify Claude Code, Git, and SimpoCLI first:

```text
claude --help
git --version
simpo --help
simpo me
```

Creating a BioModel requires `write` scope. Run `simpo configure` if `simpo me`
does not succeed. Never put the Token in a Claude prompt.

## Install from the SIMPO Marketplace

Claude Code officially supports repository Marketplaces. Run these slash
commands inside an interactive Claude Code session. Add the GitHub repository
using the documented `owner/repo` form:

```text
/plugin marketplace add Jakkwj/simpo-home
```

Install the plugin:

```text
/plugin install simpo@simpo
```

If Claude Code reports that a reload is required, run:

```text
/reload-plugins
```

Plugin Skills are namespaced, so this Skill is invoked as
`/simpo:simpo-create-biomodel`.

## Verify

Run this in the new or reloaded session:

```text
/simpo:simpo-create-biomodel What does this Skill do? Do not create anything.
```

Installation succeeded if Claude Code explains that it analyzes a paper and
prepares a reviewed Private Draft BioModel through SimpoCLI. Continue with
[Claude Code usage and examples](./biomodel-skill-claude-code-usage).

## Update

Refresh the Marketplace, update the plugin, and reload it when prompted:

```text
/plugin marketplace update simpo
```

Then open `/plugin`, select **Installed**, choose `simpo@simpo`, and
select **Update**. You may instead update it from a shell with:

```text
claude plugin update simpo@simpo
```

## Manual fallback

If the installed Claude Code version does not support plugins, update Claude
Code. As a temporary local fallback, copy the complete repository directory
`plugins/simpo/skills/simpo-create-biomodel` to
`~/.claude/skills/simpo-create-biomodel`; do not copy only `SKILL.md`, because the
workflow needs its bundled `references/` files. The fallback command is
`/simpo-create-biomodel`, without the plugin namespace.
