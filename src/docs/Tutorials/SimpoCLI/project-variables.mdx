# `get-project-variables`: read all Variable fields

Read the complete `Variable` sheet from a Project owned by the Token user. The
command returns the original field names and every row, not only `Value`.

## Requirements

- Token scope: `read`
- `PROJECT_ID`: a positive Project database ID owned by the Token user

Projects owned by other users are not enumerated. The backend returns
`HTTP 404 Project not found` for an inaccessible or nonexistent Project.

## Syntax

```text
simpo get-project-variables PROJECT_ID [OPTIONS]
```

Example:

```text
simpo get-project-variables 706
```

## Options

| Option | Default | Meaning |
| --- | --- | --- |
| `--timeout SECONDS` | `10.0` | Maximum time for the HTTP request |
| `--api-token TOKEN` | configured Token | Complete Token override |
| `--base-url URL` | packaged environment URL | Backend override for this request |

## Result

The JSON response contains Project metadata, a `columns` array, and a
`variables` array. Each item is a complete row keyed by the returned column
names. A standard row can contain:

| Field | Meaning |
| --- | --- |
| `Variable` | Variable name |
| `Tank` | Tank context, or `null` for a global Variable |
| `Value` | Current numeric value |
| `Evaluation` | Whether this Variable participates in evaluation |
| `InitialValue` | Initial value used by the calculation |
| `DecimalPoint` | Display/precision setting |
| `LowerBound` | Inclusive lower bound |
| `UpperBound` | Inclusive upper bound |

`Variable` and `Tank` are read-only identifiers. They remain in this query so
scripts can locate a row, but `set-project-variable` cannot change them. They
can only change when the source BioModel or DataSet structure is updated.

The backend may add fields in future versions. Use `columns` instead of
assuming that this standard list is exhaustive.

For automation, parse stdout and keep errors on stderr:

```bash
variables="$(simpo get-project-variables 706)" || exit $?
printf '%s\n' "$variables"
```

To change one writable field, use
[`set-project-variable`](./set-project-variable).
