# Install DataSet Skill for Codex

## Install and update with SimpoCLI

These commands require **SimpoCLI 0.1.8 or later**. Download and install a newer
CLI once if your current version does not have them.

```bash
simpo skills install simpo-create-dataset --target codex
simpo skills update simpo-create-dataset --target codex --check
simpo skills update simpo-create-dataset --target codex
```

Project installs its three dependencies automatically. Omit the Skill name to
install all four or update installed Skills. All four share a version such as
`0.1.8-skills.1`; the revision can advance independently of the CLI. Start a new
assistant session afterwards. Existing manual installations and local changes
are protected; `--force` backs them up before replacement and returns the backup
location.

Install the complete Skill directory from the repository. See the
[Skills overview](./simpo-skills) for the full directory and function table.

## Prerequisites

Codex and SimpoCLI are required. Authentication and the `write` scope are
checked by SimpoCLI and the backend only when creation is requested.

The default installation directory is
`~/.codex/skills/simpo-create-dataset`. If `CODEX_HOME` is set, use
`$CODEX_HOME/skills/simpo-create-dataset`.

## Alternative repository installation

Alternative:

```text
Use $skill-installer to install this Skill from:
https://github.com/Jakkwj/simpo-home/tree/master/plugins/simpo/skills/simpo-create-dataset
```

Manual fallback:

```bash
mkdir -p "${CODEX_HOME:-$HOME/.codex}/skills"
cp -R plugins/simpo/skills/simpo-create-dataset \
  "${CODEX_HOME:-$HOME/.codex}/skills/simpo-create-dataset"
```

Keep `SKILL.md`, `references/`, `scripts/`, and `agents/` together, then start a
new Codex session.

## Verify

Ask in the new session:

```text
What does $simpo-create-dataset do? Do not create anything.
```

Installation succeeded if Codex explains that it designs or extracts and
validates a wastewater-treatment DataSet and creates a Private Draft only after
review.
Continue with [Codex usage and examples](./dataset-skill-codex-usage).

## Update

Use `simpo skills update` above. To migrate an existing manual or Skill Installer
installation, run `simpo skills install --target codex --force`; the CLI backs it
up before taking over management.
