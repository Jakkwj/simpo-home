# `wait-operation`: wait for an asynchronous Operation

Poll an Operation until it succeeds. The command exits with a detailed error
when the backend records `failed` or `cancelled`, including `errorCode` and
`errorMessage`.

```text
simpo wait-operation OPERATION_ID [OPTIONS]
```

Example:

```text
simpo wait-operation op_abc123 --wait-timeout 86400 --poll-interval 2
```

On success, the JSON contains the final Operation record and its nested `result`.
For Project create/update, `result` is the normal Project response. For
calculation preparation, `result.launchProtocol` is available only after the
preparation succeeds; treat that protocol as a short-lived secret.

| Option | Default | Meaning |
| --- | --- | --- |
| `--wait-timeout SECONDS` | `86400` | Maximum total polling time |
| `--poll-interval SECONDS` | `2.0` | Delay between status requests |
| `--timeout SECONDS` | `10.0` | Maximum time for each HTTP request |
| `--api-token TOKEN` | configured Token | Complete Token override |
| `--base-url URL` | packaged environment URL | Backend override for this request |
