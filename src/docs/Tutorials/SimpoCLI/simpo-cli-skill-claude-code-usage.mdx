# Use SimpoCLI Skill in Claude Code

Invoke the namespaced `/simpo:simpo` command when the request should follow
the complete SimpoCLI workflow. Prompts may be in English or Chinese.

## Read-only examples

```text
/simpo:simpo List all my BioModels named ASM1 and inspect the complete tables of the newest one. Do not modify anything.
```

```text
/simpo:simpo 请查看 Project 706 的全部 Variable，并汇总 Evaluation=true 的参数，不要修改数据。
```

The Skill runs the requested command directly. SimpoCLI and the backend enforce
authentication, ownership, and scopes; it reads only the reference for the
requested command group, follows pagination, and parses JSON results. It uses
`--help` or `simpo me` only when the command reports an error, syntax is unclear,
or identity/scopes are requested.

## Write example

```text
/simpo:simpo Change Project 706, Variable S_O2 in tank AnoxicTank, field LowerBound to 0.1. Show the current row and planned change before executing it.
```

Asking how `set-project-variable` works is informational and does not authorize
the update. Public releases and other material writes require the exact target
and effect to be reviewed first.

## Calculation example

```text
/simpo:simpo Inspect Project 706, start a SIM calculation with the installed defaults, wait for a terminal status, and report the result.
```

The Skill distinguishes launch success from calculation completion. It does not
print a short-lived launch protocol unless an explicit integration requires it.

## Installed-version differences

The installed SimpoCLI and backend response are authoritative. If a requested
command is unavailable, report the error and recommend updating SimpoCLI when
appropriate. Do not bypass the CLI with direct OpenAPI requests.
