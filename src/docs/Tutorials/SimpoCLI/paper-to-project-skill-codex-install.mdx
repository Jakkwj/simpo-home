# Install in Codex

## Install and update with SimpoCLI

These commands require **SimpoCLI 0.1.8 or later**. Download and install a newer
CLI once if your current version does not have them.

```bash
simpo skills install simpo-create-project --target codex
simpo skills update simpo-create-project --target codex --check
simpo skills update simpo-create-project --target codex
```

Project installs its three dependencies automatically. Omit the Skill name to
install all four or update installed Skills. All four share a version such as
`0.1.8-skills.1`; the revision can advance independently of the CLI. Start a new
assistant session afterwards. Existing manual installations and local changes
are protected; `--force` backs them up before replacement and returns the backup
location.

Ask Codex's built-in Skill Installer to install the Skill from the repository:

```text
Use $skill-installer to install these Skills from:
https://github.com/Jakkwj/simpo-home/tree/master/plugins/simpo/skills/simpo
https://github.com/Jakkwj/simpo-home/tree/master/plugins/simpo/skills/simpo-create-biomodel
https://github.com/Jakkwj/simpo-home/tree/master/plugins/simpo/skills/simpo-create-dataset
https://github.com/Jakkwj/simpo-home/tree/master/plugins/simpo/skills/simpo-create-project
```

Install all four together: Project reuses the BioModel and DataSet workflows,
including DataSet's figure helpers, and the SimpoCLI command reference.

The Project Skill's default directory is:

```text
~/.codex/skills/simpo-create-project
```

When `CODEX_HOME` is set, the directory is:

```text
$CODEX_HOME/skills/simpo-create-project
```

Restart or start a new Codex turn after installation. SimpoCLI must be installed
separately and configured when the workflow is ready to create Drafts.
