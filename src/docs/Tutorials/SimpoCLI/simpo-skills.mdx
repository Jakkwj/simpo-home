# SIMPO Skills Overview

This page is the directory for the AI Skills available for SIMPO. It shows
what each Skill does, how to invoke it in Codex or Claude Code, where a direct
installation is placed, and where to find the detailed installation and usage
guides.

The Codex and Claude Code packages use the same Skill content; only the
installation and invocation syntax differs.

## Current Skills

| Skill | Main function | Codex | Codex installation directory | Claude Code | Claude Code installation directory |
| --- | --- | --- | --- | --- | --- |
| [SimpoCLI](./simpo-cli-skill) | Operate the installed SimpoCLI: authentication, BioModels, DataSets, Projects, Variables, calculations, and paginated results. | `$simpo` | `$CODEX_HOME/skills/simpo`<br />Default: `~/.codex/skills/simpo` | `/simpo:simpo` | Recommended: managed by the `simpo` plugin.<br />Fallback: `~/.claude/skills/simpo` |
| [SIMPO BioModel](./biomodel-skill) | Build a reviewed BioModel from a paper or explicit user-defined components, reactions, and kinetics; record supported derivations. | `$simpo-create-biomodel` | `$CODEX_HOME/skills/simpo-create-biomodel`<br />Default: `~/.codex/skills/simpo-create-biomodel` | `/simpo:simpo-create-biomodel` | Recommended: managed by the `simpo` plugin.<br />Fallback: `~/.claude/skills/simpo-create-biomodel` |
| [SIMPO DataSet](./dataset-skill) | Design from engineering conditions or extract a treatment process, operating data, and time series from papers/reports; validate the SIMPO tables and prepare a reviewed DataSet. | `$simpo-create-dataset` | `$CODEX_HOME/skills/simpo-create-dataset`<br />Default: `~/.codex/skills/simpo-create-dataset` | `/simpo:simpo-create-dataset` | Recommended: managed by the `simpo` plugin.<br />Fallback: `~/.claude/skills/simpo-create-dataset` |

Claude Code's recommended Marketplace installation is managed by Claude Code.
The fallback paths above are the direct personal Skill directories used when
plugin support is unavailable.

## Choose a Skill

- Use **SimpoCLI** when the task operates on existing SIMPO resources or runs a
  calculation. Examples include reading Project Variables, updating a Draft
  BioModel, or checking calculation status.
- Use **SIMPO BioModel** when the task starts with a paper or explicit model specification and needs a
  scientifically reviewed BioModel. It asks for review before creating the
  Private Draft through SimpoCLI.
- Use **SIMPO DataSet** when the task starts with wastewater-treatment design
  conditions, an existing process, or source literature and needs complete,
  evidence-aware, hydraulically checked DataSet tables.
- Use **SIMPO Project** when one SCI paper should produce a linked BioModel,
  DataSet, and Project. It coordinates the two extraction workflows and adds a
  calibrated figure-data step for values that appear only in plots.
- Combine the specialized Skills with SimpoCLI when the resulting BioModel or
  DataSet must later be inspected, updated, released, or used in a Project.

## Python and Poppler requirements

The ordinary `simpo` CLI commands do **not** require a user-installed Python
environment or Poppler. The requirements below apply only when the DataSet or
Project paper workflow must render PDF pages or normalize a digitizer export:

| Workflow | Required local tools |
| --- | --- |
| Design inputs, text/tables, supplied images, or supplied digitizer CSV/JSON | None for these helpers |
| Bundled figure helpers | Python 3 |
| Rendering PDF pages with `prepare_paper_figures.py` | Python 3 and Poppler `pdftoppm` |
| Automatic PDF page-count lookup | `pdfinfo` is optional when a page range is supplied |

Before rendering, the Skill checks:

```bash
python3 --version
pdftoppm -v
```

If a required tool is missing, the figure-dependent step pauses and the Skill
explains how to install it or use an equivalent renderer. It does not claim
that rendering or digitization completed. SimpoCLI's `calculate` command has a
separate requirement: the matching SimpoClient installation.

## Install the Skills

### Codex

Ask Codex's built-in Skill Installer to install the required repository path:

```text
Use $skill-installer to install this Skill from:
https://github.com/Jakkwj/simpo-home/tree/master/plugins/simpo/skills/simpo
```

For the BioModel Skill, replace the final path with
`plugins/simpo/skills/simpo-create-biomodel`; for the DataSet Skill, use
`plugins/simpo/skills/simpo-create-dataset`; for the paper workflow, use
`plugins/simpo/skills/simpo-create-project`. Manual installation copies the
complete directory, including `SKILL.md` and `references/`, to the matching
`$CODEX_HOME/skills/<skill-name>` directory. Include `scripts/` when present.
For the Project workflow, install all four Skills: it reuses the BioModel and
DataSet workflows and the SimpoCLI command reference. Restart Codex after installation.

### Claude Code

The recommended installation installs the single `simpo` plugin, which contains
all current Skills:

```text
/plugin marketplace add Jakkwj/simpo-home
/plugin install simpo@simpo
```

After a reload, use the namespaced commands shown in the table. If the Claude
Code version cannot install plugins, copy each complete Skill directory to its
matching `~/.claude/skills/<skill-name>` fallback path.
