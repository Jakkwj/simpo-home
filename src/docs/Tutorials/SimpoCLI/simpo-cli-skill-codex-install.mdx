# Install SimpoCLI Skill for Codex

## Install and update with SimpoCLI

These commands require **SimpoCLI 0.1.8 or later**. Download and install a newer
CLI once if your current version does not have them.

```bash
simpo skills install simpo --target codex
simpo skills update simpo --target codex --check
simpo skills update simpo --target codex
```

Project installs its three dependencies automatically. Omit the Skill name to
install all four or update installed Skills. All four share a version such as
`0.1.8-skills.1`; the revision can advance independently of the CLI. Start a new
assistant session afterwards. Existing manual installations and local changes
are protected; `--force` backs them up before replacement and returns the backup
location.

Install the Skill directly into Codex's Skill directory.

See the [Skills overview](./simpo-skills) for the complete Codex/Claude Code
directory and function table.

## Prerequisites

Codex and the separately installed SimpoCLI are required:

```text
codex --help
simpo --version
simpo --help
```

If authentication is not configured, configure a Token interactively when you
need to run a command:

```text
simpo configure
```

Never paste the Token into Codex.

The default installation directory is `~/.codex/skills/simpo`. When
`CODEX_HOME` is set, use `$CODEX_HOME/skills/simpo` instead.

## Alternative repository installation

Alternatively, ask Codex's built-in Skill Installer to install the
Skill from GitHub:

```text
Use $skill-installer to install this Skill from:
https://github.com/Jakkwj/simpo-home/tree/master/plugins/simpo/skills/simpo
```

If the built-in installer is unavailable, copy the complete Skill directory to
Codex's local Skill directory. Keep `references/` with `SKILL.md`:

```bash
mkdir -p "${CODEX_HOME:-$HOME/.codex}/skills"
cp -R plugins/simpo/skills/simpo \
  "${CODEX_HOME:-$HOME/.codex}/skills/simpo"
```

Start a new Codex session after installation.

## Verify

Ask:

```text
What does $simpo do? Do not change anything.
```

Installation succeeded if Codex explains that it routes requests to the
installed SimpoCLI and safely operates SIMPO resources.

## Update

Use `simpo skills update` above. To migrate an existing manual or Skill Installer
installation, run `simpo skills install --target codex --force`; the CLI backs it
up before taking over management.
