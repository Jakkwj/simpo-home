# Project

Project combines one BioModel with one DataSet and provides the settings and
calculation engines used for simulation, sensitivity analysis, uncertainty
analysis, and parameter estimation.

## Project page structure

After opening a Project, the top-level tabs are:

- `Detail`: edit the Project `Solution` and open the linked BioModel and DataSet.
- `Calculation`: configure and start a calculation, then inspect its results.
- `Version`: release Draft content as numbered versions.
- `Profile`: inspect the description, paper, linked BioModel and DataSet, and
  quoted objects.

The sidebar inside `Detail` contains `Solution`, `BioModel`, and `DataSet`.
The sidebar inside `Calculation` contains `Console`, `Simulation`,
`Sensitivity`, `Uncertainty`, and `Estimation` when the corresponding result is
available.

Use [Create](./Project/Create) to make a Project and [Edit](./Project/Edit) to
learn the fields and calculation workflow.
