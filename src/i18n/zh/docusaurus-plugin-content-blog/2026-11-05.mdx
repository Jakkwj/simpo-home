完成一次模拟后，除了观察浓度曲线，您可能还想知道：系统的物质收支是否闭合？某个组分主要在哪些池体中产生，又被哪些反应消耗？

**SIMPO 1.6.0** 新增**平衡分析**功能，通过桑基图展示质量收支和反应贡献，让模拟结果更容易核对和解释。同时，SimpoClient 支持直接通过命令行升级，账户登录与 Dashboard 的使用体验也有了新的改进。

## 平衡分析：从浓度曲线到质量收支

现在，您可以在项目的 **Calculation → Simulation** 页面，点击 **平衡分析（Balance Analysis）** 图标，查看本次计算的质量平衡与反应分析。

### 质量平衡：核对系统的完整收支

物质从哪里进入系统，通过哪些过程产生或消耗，最终又从哪里离开？质量平衡将这些贡献汇总在同一张桑基图中，帮助您核对系统边界内的收支。

- **外部输入与输出**：查看进水、出水和排泥等穿过系统边界的贡献。
- **反应与物理过程**：区分生化反应、物理传质和 Constraint 补偿等收支项。
- **动态库存变化**：动态计算还会计入池内期初、期末的库存变化。

您可以按 **Composition、Component 或 Target** 选择核算项，例如模型中已定义的元素组成、某个具体组分，或通过 Conversion 定义的综合指标。桑基图中的流带宽度表示贡献量，配合下方的收支汇总与明细，可以进一步核对各项数值。

### 反应分析：定位产生和消耗的来源

对于同一个组分，产生与消耗可能同时发生。只看最终浓度或净变化，往往难以判断各个反应的作用。

**反应分析**分别展示总产生、总消耗和净产生，并保留各池体、各反应的贡献。您可以展开池体节点查看反应明细，比较哪些过程是主要的产生或消耗来源。

例如，分析氨氮时，可以查看它在不同池体、不同反应中的产生与消耗贡献，再结合质量平衡中的进出水与库存变化，理解模拟结果。

## SimpoClient 支持命令行升级

更新计算端更加方便了！SimpoClient 现在支持直接在终端查看版本、检查新版本并执行升级。

查看当前版本：

```bash
SimpoClient --version
```

检查是否有可用新版本：

```bash
SimpoClient update --check
```

执行版本升级：

```bash
SimpoClient update
```
