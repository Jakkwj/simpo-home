# 在 SimpoDash 中复现 BSM1

假设你负责一座污水厂。早晨进水量增加，池里的微生物消耗更多氧气。沿用昨天的曝气设置，今天的溶解氧还能维持在目标附近吗？如果改用探头读数调节曝气，出水会改善多少，又要多用多少电？

**BSM1（Benchmark Simulation Model No. 1，基准仿真模型一号）** 给出了可以重复这个实验的条件。它规定了一座虚拟污水厂的池体、进水、计算模型和评价办法，还给出一组可供比较的控制设置。**ASM1** 是其中描述微生物如何消耗有机物、转化氮和消耗氧的活性污泥模型。**SimpoDash** 则是本教程用来查看这座厂、运行 SIMPO 计算和比较结果的界面。[BSM1 原报告，第 1–2 节与图 1](https://www2.iea.lth.se/publications/Reports/LTH-IEA-7229.pdf)

## 复现 BSM1 前，先核对哪些特殊设置？ {#benchmark-settings}

如果是从公开 Project 克隆，先核对下表即可。**饱和溶解氧取 8 mg O₂/L 是 BSM1 的基准条件；Tank1 的 8.64 秒滞后用于对齐本教程采用的 MATLAB/Simulink 实现。** 建模真实污水厂时，这两项各有自己的选取依据。

| 在 Dash 哪里看 | 八个 BSM1 案例怎样设置 | 换成自己的污水厂时怎样判断 |
| --- | --- | --- |
| **DataSet → Tank1 → 混合进水响应** | 选**一阶滞后**，时间常数填 **8.64 秒**。它作用于原水、内回流和污泥回流混合后的总流量及组分负荷。Tank2–Tank5 选**即时混合**。[查看 Tank1 示例](./BSM1/Setup.mdx#mixed-inlet) | 若模型假设来水混合后立即进入反应池，选即时混合。需要描述这股混合来水的响应过程时，再根据现场数据确定时间常数。 |
| **DataSet → CSTR → 溶解氧饱和模型** | 选**恒定（Constant）**，饱和值填 **8 mg O₂/L**，在曝气池 Tank3–Tank5 尤其要核对。闭环 Tank5 的 **2 mg O₂/L** 是控制器的 DO 设定值。[查看池体设置](./BSM1/Setup.mdx#aeration) | 先判断饱和浓度是否应随水温变化。按淡水温度关系计算时选**淡水（Freshwater）**并填写池内水温；采用已知固定饱和值时选**恒定**。 |
| **DataSet → 曝气泵与 Flow** | 用 **KLaPump** 直接输入氧传质系数，单位 **d⁻¹**。泵的 θ 取 **1**，不随水温修正。Tank3、Tank4 各接收完整的 240 d⁻¹；Tank5 开环为 84 d⁻¹，闭环由控制器调节。[查看泵与接线](./BSM1/Setup.mdx#aeration) | 根据数据来源选泵。已有 KLa 时用 KLaPump；掌握的是风量（m³/d）和曝气器性能时，用 AirPump 从风量计算传氧。 |
| **DataSet → 列表 → 控制器** | **01、03、05、07 开环**，控制器列表为空，内回流 `Q_a` 固定为 55,338 m³/d，池 5 曝气 `KLa_5` 固定为 84 d⁻¹。**02、04、06、08 闭环**，保留两个 PI：Tank2 的硝态氮 `S_NO` 控制 `Q_a`（设定值 **1 g N/m³**），Tank5 的溶解氧 `S_O2` 控制 `KLa_5`（设定值 **2 g O₂/m³**）。复现时沿用案例保存的 PI 参数。[两条回路的完整设置](./BSM1/Setup.mdx#controller) | 按现场控制策略确认测点、设定值和受控设备。固定运行的泵可直接给定输入。 |
| **控制器 → 传感器 → 噪声来源（Noise Source）** | **04、06、08** 的两个传感器都选 **BSM1**。硝态氮用 **BSM Class B0**，噪声标准差为 **0.50 g N/m³**；溶解氧用 **BSM Class A**，标准差为 **0.25 g O₂/m³**。参考噪声每分钟一个样本，覆盖第 0–14 天。**02** 的 500 天启动使用理想传感器，界面显示 **BSM1（未启用）**，实际噪声为零。开环案例无需配置传感器噪声。 | 模拟现场仪表噪声可选**随机**并采用仪表的噪声标准差。研究理想读数时选**关闭**。 |
| **Calculation → Console → 动态输入插值** | 选 **Linear（线性）**，按相邻时间点插值得到进水流量和浓度。晴天、降雨、暴雨的输入都在变化；01、02 的恒定进水在线性插值下仍是常数。[查看插值示例](./BSM1/Setup.mdx#run) | 看每条记录代表什么。若假设两个采样值之间平滑变化，可选 Linear；泵或投加指令一直保持到下次调整时，Previous（保持前值）更符合这种操作。 |
| **Calculation → Console → 运行与输出** | 八案均用 **Dynamic（动态）**、**前向欧拉**和 **100% 输出分辨率**。复算已保存报告时，**步长容差填 5%**。01、02 动态运行 500 天以观察趋稳过程；03–08 从对应的预运行末态开始，运行 14 天。[查看求解设置](./BSM1/Setup.mdx#run) | 按研究目的选择稳态终值或动态过程。要比较轨迹，保留与实测对应的输出时刻，再通过收紧步长容差检查结果是否稳定。 |
| **DataSet → Assessment → 起始日／结束日** | 比较 EQ、OCI 等绩效指标时，03–08 用**第 7–14 天**，01、02 用**第 493–500 天**，均为各自最后一周。[查看评估窗口](./BSM1/Assessment.mdx#run) | 按实际考核周期选择起止日。比较两个运行方案时，使用相同的评价时段。 |
| **DataSet → Assessment → SP（污泥产量）** | `Change(库存, -1)` 只将**期末污泥库存**回退一条结果记录，再减去期初库存。为复现 BSM1 的 MATLAB 评估脚本，天气案例 03–08 回退 **15 分钟**，取第 13 天 23:45。稳态案例 01、02 沿用这个取法，按各自的输出间隔回退 **4 小时**，取第 499 天 20:00。排泥量仍累计整整 7 天，日均值仍除以 7。[用实际库存理解这个偏移](./BSM1/Assessment.mdx#inventory) | 如果按评估结束时刻盘点污泥，用 `Change(库存)`，即期末库存减期初库存。 |

**怎么看复现得好不好？** 打开 **计算 → 模拟**，在池体图的指标菜单选 **All（全部）**，看整个项目的 **WNSE（加权 NSE）**。越接近 1，SIMPO 的水质曲线与 MATLAB 参考曲线整体越吻合。例如，案例 03 晴天开环的 WNSE 是 **{publicWnse['03']}**。[查看八个案例的 WNSE](./BSM1/Results.mdx#wnse)

## 顺着一股污水读流程图 {#plant}

![SimpoDash 闭环流程图，主水流从左向右经过五座反应池和沉淀池，两条回流位于下方，曝气泵位于上方，两条绿色虚线为 PI 信号。](/img/bsm1/flowsheet.png)

1. **从左边的 Inflow1 走到 Tank2。** 污水带着有机物和含氮物质，以 `Q_0` 的流量进入 Tank1。Tank1、Tank2 是缺氧池，微生物可利用有机物，把回流水带来的硝态氮转化成氮气。这个过程叫**反硝化**。
2. **从 Tank3 走到 Tank5。** 这三座池有曝气。微生物利用氧降解有机物，另一类微生物把氨氮氧化为硝态氮，这叫**硝化**。在 Tank5 有一条线沿图下方回到 Tank1，标签为 `Q_a`。它把含硝态氮的混合液带回缺氧区，此时再看第一步，就能解释为什么缺氧池要接这股内回流。
3. **沿 Tank5 的另一股水走到 Tank6。** Tank6 是二沉池，接收水和污泥的混合物。颗粒向下沉，较清的水从顶层流向 **Outflow**。模型将沉淀池分成 10 层，自底向上编号。图中的进水进入第 6 层，`Tank6_10` 是出水层，`Tank6_1` 是底层。
4. **从 Tank6 底部沿线往回看。** `Q_r` 把富含微生物的回流污泥送回 Tank1，使反应池能保有足够的微生物。`Q_w` 把一部分剩余污泥送到 **Wasted**。读图时先找线的起点，Tank5 出发的 `Q_a` 运送混合液，Tank6 底部出发的 `Q_r` 运送浓缩污泥。

**用流量验算一次。** 在 01 稳态开环案例，进水 `Q_0` 为 18,446 m³/d，内回流 `Q_a` 为 55,338 m³/d，污泥回流 `Q_r` 为 18,446 m³/d。三股相加，Tank1 接收 **92,230 m³/d**。若把边界画在整座厂的围墙上，两股回流都留在厂内。稳定工况下排泥流量为 385 m³/d，最终出水就是 **18,446 − 385 = 18,061 m³/d**。这解释了流程图上池间流量为何可以远大于厂外进水。<a href={projectLinks['01'] + '?view=detail'}>查看 01 的工艺配置</a>

### 先认清读数、流量和曝气系数

| 图上或结果里看到的量 | 怎么读 | 看哪里 |
| --- | --- | --- |
| `Q_0`、`Q_a`、`Q_r`、`Q_w`（m³/d） | 每天有多少体积的液体经过这条线 | 看流线两端确认进水、内回流、污泥回流或排泥。 |
| `Tank2.S_NO`（g N/m³） | Tank2 每立方米水中硝酸盐和亚硝酸盐所含氮的质量。界面简称硝态氮。 | Tank2 是硝态氮控制回路的测点。 |
| `Tank5.S_O2`（g O₂/m³） | Tank5 的溶解氧浓度，简称 DO。2 g O₂/m³ 等于常用的 2 mg O₂/L。 | 闭环希望 DO 维持在 2 附近。池体设置中的 8 g O₂/m³ 是计算传氧所用的饱和浓度。 |
| `KLa_5`（d⁻¹） | 曝气的氧传递系数。相同条件下，池水溶解氧低于饱和值时，这个系数越大，氧进入水中的速率越快。 | 找 Tank5 上方的 KLaPump5。这个输入改变供氧强度，水量核算只加各股水流。 |
| `Tank6_10.TSS`（g SS/m³） | 顶层水中总悬浮固体的质量浓度，即每立方米出水含多少克悬浮固体。 | 查看出水含固体多少时选顶层。底层浓度用来分析回流和排泥。 |

### 为什么有开环和闭环

打开<a href={projectLinks['03'] + '?view=detail'}>03 · 晴天开环</a>，再看刚才的 04。两例使用相同的晴天进水序列。03 中，`Q_a` 固定为 **55,338 m³/d**，`KLa_5` 固定为 **84 d⁻¹**。进水流量和组成仍随时间变化，Tank5 的 DO 也会跟着变化。这就是这里的**开环**。

在 04 中，绿色虚线传递的是信号。**Sensor** 提供读数，**PI Controller** 将读数与设定值相比较，控制器输出经执行器调整操纵量，水质变化又被传感器读到，形成**闭环**。

| 跟踪哪项读数 | 目标 | 控制器调哪一条线 |
| --- | ---: | --- |
| Tank2 的硝态氮 `S_NO` | 1 g N/m³ | `BSM1_Qintr` 调节内回流 `Q_a`。 |
| Tank5 的溶解氧 `S_O2` | 2 g O₂/m³ | `BSM1_KLa5` 调节曝气系数 `KLa_5`。 |

例如探头读到 DO 为 1.8 g O₂/m³，距离目标还差 0.2。PI 的比例项会朝**增大曝气系数**的方向调节。持续存在的偏差还会累积到积分项。随后池中氧浓度如何变化，还取决于微生物的耗氧和进水带来的负荷。在 04 的 **Calculation → Simulation** 中选择 Tank5 的 `S_O2`，观察它如何在目标附近波动。[查看两条回路的参数与试调操作](./BSM1/Setup.mdx#controller)

## 参考结果的版本 {#用原报告核对结果}

**2008 年原报告**给出评价指标的定义，并列出 MATLAB/Simulink 的开环、闭环绩效值。**R2019b 发布包**提供模型、三种天气的进水和随附参考结果。本次采用该发布包的模型在 **MATLAB R2024b** 运行并导出轨迹，再与 SIMPO 逐点计算 NSE。读暴雨开环的出水负荷时尤其要核对参考版本，各版本的数值存在差异。[2008 年报告附录 4–5](https://www2.iea.lth.se/publications/Reports/LTH-IEA-7229.pdf#page=40) · [BSM1 官方模型发布包](https://github.com/wwtmodels/Benchmark-Simulation-Models/releases/tag/BSM1_vR2019b)

BSM1 基准由 IWA 工作组制定。本文使用的 MATLAB/Simulink 实现由瑞典隆德大学 IEA 的 Ulf Jeppsson、Christian Rosen 等人开发。使用该实现发表论文时，请按发布包 `Documents/BSM1_agreement_LU.pdf` 的说明注明来源。[IWA 工作组发布包及随附说明](https://github.com/wwtmodels/Benchmark-Simulation-Models/releases/tag/BSM1_vR2019b)
