# 平衡分析

平衡分析用于回答三个问题：所选物质或指标从系统外进入了多少、通过哪些过程产生或消耗、最后的收支是否在容差内闭合。它读取本次计算保存的结果，在同一个窗口中提供**质量平衡**、**反应分析**和有异常时的**异常汇总**。

支持普通模拟（Simulation），以及不确定性分析（Uncertainty）和参数估计（Estimation）结束后的最优解模拟。

建议先看质量平衡，确认系统边界和总收支；再看反应分析，定位产生或消耗来自哪些池体、哪些反应。

## 如何获得平衡结果 {#getting-results}

1. 打开可编辑的 Project 草稿，检查 BioModel、DataSet 和 Solution。修改后先解析并保存项目。
2. 在 **Calculation → Console** 选择 **Simulation（SIM）**，使用稳态、动态或先稳态后动态模式计算。
3. 等待计算完成、结果保存后，打开 **Calculation → Simulation** 查看结果。

平衡结果与这一次运行绑定。计算结束后再修改模型系数、Conversion 或计算设置，不会更新已经保存的平衡结果；要分析修改后的模型，需要重新计算。

| 计算模式 | 可以查看的平衡结果 | 数值含义 |
| --- | --- | --- |
| 稳态 | 稳态平衡 | 终态下的速率，例如 `kgN/d`。判断稳态闭合还需要确认已经收敛。 |
| 动态 | 动态平衡 | 整个动态模拟区间的累计量，例如 `kgN`，并计入期初、期末库存变化。 |
| 先稳态后动态 | 稳态和动态平衡 | 两个阶段分别查看；动态累计量不包含此前求稳态所用的时间。 |

单位随所选核算项变化。例如氮使用氮质量单位，COD 使用 COD 当量单位，Charge 可以使用电荷物质的量单位。图中的量不是原始浓度，请以当前图表标注的单位为准。

### 不确定性分析和参数估计的最优解

照常运行不确定性分析或参数估计。搜索结束后，计算程序用选中的最优参数**再模拟一次**，保存完整的收支贡献。这次模拟沿用本次运行的计算模式、求解设置和输出分辨率。

平衡结果只代表这一组最优参数，**不是所有候选的平均平衡，也不是预测区间的平衡**。拟合效果好与收支在容差内闭合是两个不同的检查。新增工作量是搜索完成后的一次模拟，不是给每个候选额外再算一次。

需要使用支持此功能的计算端，并重新准备支持最优解模拟的计算程序。旧结果中仅有最优拟合曲线时，无法据此补出完整收支。没有可用最优解、没有完成平衡快照保存，或缺少用于确认最优解来源的保存信息时，网页中的平衡分析不可用。

### 为什么旧案例没有平衡结果？

旧计算可能保存了浓度曲线，但没有保存平衡分析所需的反应、物理过程或收支明细。**重新打开网页、解析 BioModel 或保存项目，都不能为旧结果补出这些数据。**

请使用支持平衡分析的计算端重新运行。若设置没有变化，勾选 **Recalculate**，避免复用旧计算结果。旧版平衡数据有时仍可显示，但页面会提示其范围限制；完整核算应使用新计算产生的结果。

## 在哪里打开 {#open-analysis}

在项目草稿的 **Calculation → Simulation** 页面，找到结果操作栏中的 **平衡分析（Balance Analysis）** 图标。将鼠标移到图标上可以看到名称，点击后打开独立弹窗。

查看最优解时，在 **Calculation → Uncertainty** 或 **Calculation → Estimation** 的结果操作栏点击提示为**最优解模拟的平衡分析**的图标。弹窗会标明最优解来源，显示该次最优解模拟的结果，不借用项目中另一次 Simulation 的结果。请等待最终结果保存并加载完成。

按钮在结果加载中或没有可用平衡结果时不可点击。有浓度曲线不代表一定有平衡结果。
核算项不完整、差异超限或稳态未收敛时，仍可打开已有结果排查原因。

弹窗包含以下操作：

- **稳态／动态**：结果包含相应阶段时，在标题旁切换。
- **质量平衡（Mass Balance）**：查看完整收支、桑基图和通量明细。
- **反应分析（Reaction Analysis）**：查看生化总产生、总消耗及池体和反应贡献。
- **异常汇总**：集中查看需要关注的核算项和结果提示；没有异常或提示时隐藏。
- **右上角全屏图标**：放大弹窗，方便查看列数较多的图表。

拖动节点的色块可以调整位置，相连分支随之移动，数值与比例保持不变。单击可展开的汇总节点仍可展开或收起明细。下载图片保留当前布局；手动位置不会在刷新页面、切换核算项或改变展开状态后继续保留。

稳态／动态及质量平衡／反应分析分别保留筛选项。在同一项目页面中切换页签或关闭后重新打开弹窗，可以恢复各自的选择；刷新页面或切换项目后不保证保留。

## 选择核算维度与核算项 {#dimensions}

先选择 **Composition、Component 或 Target**，再选择右侧的具体核算项。选项按模型或项目原有顺序排列；没有可显示核算项的维度不会保留一个空下拉框。

| 维度 | 代表什么 | 适合回答的问题 |
| --- | --- | --- |
| Composition | 按 BioModel 的 Composition 系数，将各 Component 换算为同一种核算量，例如 N、P、S 或 ThOD。 | 全厂的氮是否闭合？各股进出水携带多少氮？ |
| Component | 模型中的单个组分，例如 `S_NH4`、`S_NO2`、`S_O2`；名称以当前模型为准。 | 该组分消耗多少？在哪个池、哪个反应中产生？ |
| Target | 按 Solution 的 Conversion 将 Component 合并为指标，例如 COD 或 TSS。 | 某个综合指标的进出水、反应和库存贡献分别是多少？ |

### Composition 为什么没有某一项？

Composition 必须由模型提供实际系数。没有提供 Composition 时不会自动猜测元素组成；原本整行为空的定义也不会显示。已提供的行中，现有 Component 列的空白单元格按 BioModel 的规则视为 0，例如核算 S 时，不含硫组分的系数可以留空。缺少 Component 列或非空表达式无法解析时，仍会提示核算不完整。

解析保存模型后仍需重新计算，并确认该 Project 使用的确实是更新后的模型。已有结果继续使用当次计算保存的定义。

### Target 为什么比 DataSet 中的数量少？

如果某个 Target 的 Conversion **只有一个非零系数且等于 1**，它与对应 Component 是同一个核算量，不重复显示。单位标签是否相同不影响这项去重规则；请到 Component 中查看。

其余 Target 会保留，并在进出水明细中按 Component 展开贡献。若全部 Target 都与 Component 重复，则不显示 Target 维度。核算也不仅限于氨氮，其他 Component 同样可以选择；缺少支持条件的项会显示相应提示。

## 如何阅读质量平衡 {#mass-balance}

质量平衡同时考虑**外部进出水、生化反应净值、物理过程、Constraint 补偿**，动态结果还考虑**池内库存变化**。

以一个非负质量指标为例，动态收支可以写成：

```text
期初库存 + 外部输入 + 生化净产生 + 物理净输入 + Constraint 净补偿
    = 期末库存 + 外部输出
```

生化净产生、物理净输入或约束净补偿都可能为负。实际图表会把正贡献放在“输入／源”侧，把负贡献的幅值放在“输出／汇”侧，并单独报告两侧差值。

### 哪些量计入，哪些不重复计入？

| 收支项 | 如何理解 |
| --- | --- |
| 进水、出水、排泥 | 只统计穿过全厂外部边界的流。进出水可按各股流及其 Component 贡献展开。 |
| 内部回流、池间输送 | 在全厂内部转移，不重复计作全厂输入或输出。 |
| 生化反应 | 先计算每个池体的净产生或净消耗，再汇总。净产生等于总产生减总消耗。 |
| 物理过程 | 模型中已描述的交换，例如曝气传质供氧；与水流携带量、生化反应分开核算。 |
| Constraint | 为满足约束状态所需的补偿；根据收支缺口反推的补偿会明确标注。 |
| 库存变化 | 动态阶段期末储存量减去期初储存量。增加放在输出／汇侧，减少放在输入／源侧。 |

**物理供氧与 Constraint 补偿不是一回事。**前者来自模型中的传质过程；后者可能是为维持指定溶解氧浓度而反推的需求。含反推补偿的闭合，不能独立证明实际供氧或加药量正确，也不能再把同一供氧量重复添加一次。

当前模拟的稳态和动态阶段都应用已配置的 Constraint。稳态使用按所选稳态输入平均方法计算的约束值，不做流量加权；动态使用随时间变化的约束值。历史结果应以当次运行实际应用的约束和保存明细为准。动态反推值是每池、每个 Component 在全时段的**累计净补偿**，不能据此分辨过程中累计补加和累计移除各有多少。

### 桑基图的宽度与百分比

从左向右阅读：各股输入和正贡献汇总到中间，再展开输出和负贡献。存在多股流时保留流汇总层；只有一股时可省略重复层。点击可展开的汇总节点，可以展开或收起明细；也可以使用**全部展开／全部收起**。

- 流带宽度表示当前单位下的贡献量，节点同时显示实际数值。
- 左侧百分比以**总输入／源**为分母，右侧以**总输出／汇**为分母。
- 因此两侧都显示 `100%`，只表示各自加总为本侧总量，**不代表两侧数值相等**。
- 零值不绘制流带；分母为零时，百分比显示为不适用。

图下的“完整收支汇总”便于核对总量，“带符号通量明细”用于查明各条贡献来自哪股流、哪个池或哪类过程。系统不会为了让图看起来闭合而添加虚构的补平流量。

对于 ThOD、Charge 等可能带负系数的核算量，输入的某个 Component 也可能贡献负当量并显示在另一侧。此时图的左右代表**代数收支方向**，不完全等同于物理水流方向；请结合带符号明细阅读。

### 没有进水的 Batch 如何分析？

Batch 从初始浓度开始反应，仍可以核算。期初和期末的质量由保存的池容与浓度共同计算，变容池使用各时刻实际池容。

例如，一个无进出水的 Batch，NO₃ 初始库存为 `100 mgN`，期末为 `30 mgN`，累计反应净消耗为 `70 mgN`。图中会把 `70 mgN` 的库存减少作为源，与 `70 mgN` 的反应净消耗对应。这是库存释放，不是虚构的进水。

以上只是说明读图方式的示意数字。实际案例应核对自己的期初、期末库存及累计反应量。

## 如何阅读反应分析 {#reaction-analysis}

反应分析回答“哪些反应产生或消耗了这个核算量”。它保留每个池体和每个反应的贡献，显示**总产生、总消耗和净产生**，不包含进出水、池间输送、物理传质、Constraint 和库存变化。

产生和消耗在同一张图中使用统一的宽度比例，可以直接比较两侧流带大小；中间节点仅标识正在分析的核算项，**不是一个产生量或库存量**。产生侧百分比以总产生为分母，消耗侧以总消耗为分母。

两侧不要求相等。例如，某组分没有产生反应，但累计消耗了 `0.002 kg`，图中会显示“无产生反应”，只绘制消耗侧流带。这不表示凭空消耗；它可能由初始库存、进水或其他过程供给，应回到质量平衡查看。

下方提供两张表：

- **分池反应汇总**：每个池体的总产生、总消耗、净产生。
- **逐池、逐反应明细**：进一步定位具体反应，并查看其占全厂产生或消耗总量的比例。

点击池体汇总节点可以收起或展开反应明细。池体表只是该池的**反应汇总**，不是包含相邻池输送、物理过程和库存变化的完整单池平衡。

对于 Composition 和 Target，先在每个池体、每个反应内按系数合并组分贡献，再判断产生或消耗。例如，反应把一种含氮组分转为另一种含氮组分，单个 Component 会有产生和消耗，但总 N 的该反应贡献可能为零。

## 如何处理异常与闭合状态 {#diagnostics}

先打开**异常汇总**，查看需要关注的核算项。点击某一行的**质量平衡**或**反应分析**，会跳转并选中该项，无需逐个下拉查找。顺序为 Composition、Component、Target，各维度内部保留原定义顺序。

| 提示或状态 | 含义与下一步 |
| --- | --- |
| 容差内闭合 | 已保存的完整收支满足核算容差；稳态还要求收敛已确认。 |
| 稳态未收敛／收敛状态未知 | 终态数据可以诊断，但还不能作为已达到稳态的闭合结论。先查看计算报告和日志。 |
| 核算不完整 | 某些系数、过程或浓度数据不可用。查看具体原因，不能将缺失项当作零。 |
| 含反推约束补偿的收支闭合 | 缺口包含根据约束反推的补偿，需结合约束与实际过程判断。 |
| 累计收支核算差异超限 | 动态累计差异超过容差，需进一步定位原因；不等同于已经证明模拟错误。 |

出现负值或非有限浓度时，展开诊断信息，查看具体 **Component、Tank、异常类型、出现时间与数值**。一个组分的问题也可能影响含有它的 Composition 或 Target。负的投影系数或负的反应贡献，本身不等于浓度出现了负值。

### “各反应均保持此量不变”是什么意思？

这是对模型每个反应的检查，包括本次运行中未发生的反应。**是**表示每个反应都不改变该核算量；**否**表示至少一个反应能够产生或消耗它。

这与完整收支闭合是两个问题。总 N 可能被所有生化反应保持不变，而氨氮、TSS 或 COD 指标可以被反应改变。只要相应反应项被正确计入，它们的完整收支仍可闭合；不能只比较进水与出水便判定不守恒。

### 绝对差值、相对差值与容差

```text
绝对差值 = |总输入／源 − 总输出／汇|
相对差值 = 绝对差值 ÷ (总输入／源 + 总输出／汇) × 100%
```

动态页面使用绝对差值展示偏离程度；带符号明细和 Excel 中的残差仍保留方向。相对差值不是浓度的相对误差，也不是单独以进水负荷为分母计算的百分比。

仅当**绝对差值和相对差值都超出各自容差**时，才因数值差异给出超限提示。分母为零时，应查看系统报告的状态，不能自行除零。页面底部显示本次结果使用的容差；这是核算判断阈值，与求解器的 Step Tolerance 不同。

## 动态积分精度如何理解 {#dynamic-accuracy}

动态平衡累计整个模拟区间，不需要另选起止日期。页面显示区间、时长、分辨率和保存时间点数；将鼠标移到**保存时间点**说明上，可以查看本次结果保存的积分方法。

当前新结果使用三次样条积分（not-a-knot），对已保存时间点上的通量进行后处理积分。旧结果可能仍使用梯形法等已保存的方法；打开页面不会把旧结果自动换成新算法。

后处理没有使用求解器内部的每一个步，也不会为了绘制图形改变已保存的模拟浓度。三次样条可以改进采样点之间的近似，但无法还原未保存的快速变化，不能保证收支严格闭合。

**提高分辨率**可以得到更多保存时间点，改善后处理积分精度；减小求解容差主要改善数值解的精度，两者作用不同。比较时应重新计算，并同时观察绝对差值和相对差值是否稳定。

例如 NO₂ 可能有大量产生和消耗，但两者相互抵消后的净量很小。较小的累计积分偏差，也可能相对于这个净收支表现为较大的百分比。需要结合总产生、总消耗和库存变化判断，不能只看一个百分数。

出现“保存的采样点未充分反映输入变化”时，表示输入时间节点未匹配保存时间点，或阶梯输入缺少变化前后的记录；历史数据缺少覆盖信息时也可能提示。它只检查节点和记录情况，**并未确认输入值真的发生变化**，也不能给出误差大小。

建议按以下顺序检查：

1. 核对流量、浓度等输入曲线，在提示涉及的时间节点是否实际变化。
2. 核对进出水、反应、物理传质、Constraint 和库存等项是否齐全。
3. 必要时提高输出分辨率或求解精度，重新计算后比较差值。

增加保存点不保证覆盖输入变化的两侧，也不保证提示消失或差值归零。页面会说明：**该差异可能来自后处理积分、数值求解或收支项缺失，尚不能仅据此判定模拟错误。**

## 下载图片与 Excel 数据 {#export}

桑基图上方的**下载图片**下拉菜单提供 **PNG** 和 **SVG**。下载包含当前展开或收起状态下的完整图形，包括滚动区域中暂时看不到的部分。需要进一步排版或缩放时，可以选择 SVG。

图片名称以 `Balance__` 开头，包含核算维度和核算项；动态图额外包含 `Dynamic`，反应图额外包含 `Reaction`。例如：

```text
Balance__Composition__N.svg
Balance__Component__S_O2__Reaction.png
Balance__Dynamic__Target__COD.svg
```

图形按需在网页生成；本地计算结果不需要预先生成每个核算项的图片。需要数字时，打开本次计算的结果目录并使用 Excel 文件：

- **稳态**：`Result__SIM__SteadyState__.xlsx`。
- **动态**：`Result__SIM__.xlsx` 中的平衡工作表。

最优解的这两类工作簿保存在对应的 **Uncertainty** 或 **Estimation** 运行目录中，通过该次结果的目录按钮打开。不要混用另一次 Simulation 的同名文件。

| 工作表 | 用途 |
| --- | --- |
| `BalanceSummary` | 各核算项的全厂收支汇总、差值与判断依据。动态结果另有期初、期末库存与库存变化。 |
| `BalanceTerms` | 完整的带符号收支明细，用于追溯各条输入、输出和过程贡献。 |
| `BalanceReactions` | 逐池、逐反应的产生、消耗和净值。 |
| `BalanceTanks` | 将 `BalanceReactions` 按池体汇总，不包含池间输送等完整单池收支项。 |

稳态核算说明放在 `Metadata` 中，动态另有 `BalanceMetadata`，用于核对范围、积分方法等信息。表头批注解释各列含义；稳态批注按计算请求的语言生成，默认英文，动态批注当前为英文。切换网页语言不会改写已保存的工作簿。

## 常见问题 {#faq}

### 是否可以追踪“某股进水中的氨氮最终变成了多少 NO₃、N₂ 或生物量”？

当前分析不做来源追踪。它可以显示这些组分各自的收支，以及反应对它们的产生和消耗贡献，但不能把某股进水与最终产物一一对应。图中流带汇合不代表已经建立了这种来源去向关系。

### ThOD、Charge 等带负系数的量可以分析吗？

可以按已提供的定义进行带符号核算，不只限于单元素。应同时查看反应、物理过程及必要的约束项，并注意负当量在图中的方向。是否被所有反应保持不变，应看实际模型检查结果，而不是只依据指标名称。

### 图没画出来，是不是没有反应或没有流量？

不一定。可能所有贡献都是零，也可能数据缺失或无效。先读图旁提示和明细表：明确为零的项保留在表里；缺失、不支持或无效的数据不能解释为零。

需要通过终端获取同一结果时，可参阅 [get-calculation-result 命令参考](../SimpoCLI/get-calculation-result)。
