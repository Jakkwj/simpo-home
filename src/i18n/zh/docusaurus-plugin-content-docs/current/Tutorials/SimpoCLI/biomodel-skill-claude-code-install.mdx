# 在 Claude Code 中安装 BioModel Skill

Claude Code 版本通过 SIMPO Marketplace 中的 `simpo` 插件发布。该插件同时包含两项
SIMPO Skill，其中 `simpo-create-biomodel` 工作流包含论文分析所需的三份参考资料。

## 安装前准备

先确认 Claude Code、Git 和 SimpoCLI 可用：

```text
claude --help
git --version
simpo --help
simpo me
```

创建 BioModel 需要 API Token 的 `write` scope。如果 `simpo me` 失败，请先运行
`simpo configure`。不要在 Claude 提示词中放入 Token。

## 从 SIMPO Marketplace 安装

Claude Code 官方支持仓库 Marketplace。请在 Claude Code 交互会话中运行以下斜杠命令，
并按官方记录的 `owner/repo` 格式添加 GitHub 仓库：

```text
/plugin marketplace add Jakkwj/simpo-home
```

安装插件：

```text
/plugin install simpo@simpo
```

如果 Claude Code 提示需要重新加载，请运行：

```text
/reload-plugins
```

插件 Skill 带有命名空间，因此应通过
`/simpo:simpo-create-biomodel` 调用。

## 验证

在新会话或重新加载后的会话中运行：

```text
/simpo:simpo-create-biomodel 请说明这个 Skill 的作用，不要创建任何内容。
```

如果 Claude Code 能说明它会分析论文，并通过 SimpoCLI 准备一个经过审查的
Private Draft BioModel，则安装成功。下一步参阅
[Claude Code 使用方法与示例](./biomodel-skill-claude-code-usage)。

## 更新

先刷新 Marketplace，再更新插件，并在提示时重新加载：

```text
/plugin marketplace update simpo
```

然后打开 `/plugin`，进入 **Installed**，选择 `simpo@simpo` 并点击
**Update**。也可以在终端中运行：

```text
claude plugin update simpo@simpo
```

## 手工安装备用方案

如果当前 Claude Code 不支持插件，请先升级 Claude Code。临时本地安装时，可将仓库中
`plugins/simpo/skills/simpo-create-biomodel` 整个目录复制到
`~/.claude/skills/simpo-create-biomodel`；不能只复制 `SKILL.md`，因为工作流还需要
`references/` 中的资料。此时调用命令为 `/simpo-create-biomodel`，不带插件命名空间。
