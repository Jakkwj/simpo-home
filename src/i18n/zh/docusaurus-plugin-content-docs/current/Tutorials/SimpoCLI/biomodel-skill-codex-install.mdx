# 在 Codex 中安装 BioModel Skill

## 使用 SimpoCLI 安装和更新

SimpoCLI **0.1.8 起**支持以下命令；旧 CLI 需要先下载安装新版。

```bash
simpo skills install simpo-create-biomodel --target codex
simpo skills update simpo-create-biomodel --target codex --check
simpo skills update simpo-create-biomodel --target codex
```

安装 Project 会补齐另外三项依赖。省略名称时安装全部四项，更新命令更新已安装的
Skills。四项共用 `0.1.8-skills.1` 这样的版本，后缀独立递增。已有手工安装或本地
修改时默认停止覆盖；加 `--force` 会先备份，并返回备份目录。完成后开启新的助手会话。

直接从仓库将 Skill 安装到 Codex 的 Skill 目录。

完整的 Skill 安装目录和功能对照请参阅 [Skill 总览](./simpo-skills)。

## 安装前准备

需要安装 Codex 和 SimpoCLI。创建命令执行时，CLI/后端会检查认证和 `write` scope：

```text
codex --help
simpo --help
```

如果尚未保存有效 Token，需要执行创建命令时再交互运行 `simpo configure`。默认 Skill
目录为 `~/.codex/skills/simpo-create-biomodel`；如果设置了 `CODEX_HOME`，则使用
`$CODEX_HOME/skills/simpo-create-biomodel`。

## 从仓库安装的备用方式

备用方式：

```text
Use $skill-installer to install this Skill from:
https://github.com/Jakkwj/simpo-home/tree/master/plugins/simpo/skills/simpo-create-biomodel
```

手工备用方式：

```bash
mkdir -p "${CODEX_HOME:-$HOME/.codex}/skills"
cp -R plugins/simpo/skills/simpo-create-biomodel \
  "${CODEX_HOME:-$HOME/.codex}/skills/simpo-create-biomodel"
```

必须保留 `references/` 与 `SKILL.md`，然后重新开启 Codex 会话。

## 验证

在新会话中询问 Codex：

```text
请说明 $simpo-create-biomodel 的作用，不要创建任何内容。
```

如果 Codex 能说明它会分析论文并通过 SimpoCLI 创建 Private Draft BioModel，则安装成功。
下一步参阅 [Codex 使用方法与示例](./biomodel-skill-codex-usage)。

## 更新

推荐使用上方 `simpo skills update`。旧安装器或手工复制的目录，首次迁移使用
`simpo skills install --target codex --force`，先备份再纳入 CLI 管理。
