# 在 Codex 中安装 SimpoCLI Skill

## 使用 SimpoCLI 安装和更新

SimpoCLI **0.1.8 起**支持以下命令；旧 CLI 需要先下载安装新版。

```bash
simpo skills install simpo --target codex
simpo skills update simpo --target codex --check
simpo skills update simpo --target codex
```

安装 Project 会补齐另外三项依赖。省略名称时安装全部四项，更新命令更新已安装的
Skills。四项共用 `0.1.8-skills.1` 这样的版本，后缀独立递增。已有手工安装或本地
修改时默认停止覆盖；加 `--force` 会先备份，并返回备份目录。完成后开启新的助手会话。

将 Skill 直接安装到 Codex 的 Skill 目录。

完整的 Codex/Claude Code 安装目录和功能对照请参阅 [Skill 总览](./simpo-skills)。

## 安装前准备

需要安装 Codex 和单独的 SimpoCLI：

```text
codex --help
simpo --version
simpo --help
```

如果尚未配置认证，需要执行命令时再在终端中交互配置 Token：

```text
simpo configure
```

不要把 Token 粘贴到 Codex 中。

默认安装目录为 `~/.codex/skills/simpo`；如果设置了 `CODEX_HOME`，则使用
`$CODEX_HOME/skills/simpo`。

## 从仓库安装的备用方式

也可以让 Codex 内置的 Skill Installer 从 GitHub 安装：

```text
Use $skill-installer to install this Skill from:
https://github.com/Jakkwj/simpo-home/tree/master/plugins/simpo/skills/simpo
```

如果内置安装器不可用，可将完整 Skill 目录复制到 Codex 的本地 Skill 目录；必须保留
`references/` 与 `SKILL.md`：

```bash
mkdir -p "${CODEX_HOME:-$HOME/.codex}/skills"
cp -R plugins/simpo/skills/simpo \
  "${CODEX_HOME:-$HOME/.codex}/skills/simpo"
```

安装后重新启动 Codex 会话。

## 验证

询问：

```text
请说明 $simpo 的作用，不要执行任何修改。
```

如果 Codex 能说明它会调用当前安装的 SimpoCLI 并安全操作 SIMPO 资源，则安装成功。

## 更新

推荐使用上方 `simpo skills update`。旧安装器或手工复制的目录，首次迁移使用
`simpo skills install --target codex --force`，先备份再纳入 CLI 管理。
