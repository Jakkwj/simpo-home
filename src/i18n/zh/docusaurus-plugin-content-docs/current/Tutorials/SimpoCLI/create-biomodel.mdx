# `create-biomodel`：新建 Draft BioModel

新建一个属于当前 API Token 用户的 BioModel。不传导入选项时使用 SIMPO 标准空白
模型；传入 `--template` 时解析指定的 Excel 模型，传入 `--json` 时解析 JSON
模型表。三种方式返回相同的 JSON 结构。

## 使用条件

- Token scope：`write`
- 名称长度为 1 到 230 个字符，并且不能与当前账户已有的任意 BioModel 重复。

第一版 OpenAPI 只创建 Draft。后端会固定其元数据为
`state=Draft`、`privacy=Private`、`version=0`。

## 命令格式

```text
simpo create-biomodel NAME [OPTIONS]
```

示例：

```text
simpo create-biomodel MyModel
simpo create-biomodel MyModel --description "由自动化脚本创建"
simpo create-biomodel MyModel --sourcepaper-id 123
simpo create-biomodel ImportedModel --template ./BioModel.xlsx
simpo create-biomodel JsonModel --json ./BioModel.json
```

## 选项

| 选项 | 默认值 | 作用 |
| --- | --- | --- |
| `--description TEXT` | 空字符串 | 可选的 Markdown 描述 |
| `--sourcepaper-id ID` | 无来源论文 | 来源论文数据库 ID |
| `--template PATH` | 标准空白模型 | `.xlsx` 模型模板；不能为空且最大为 20 MiB |
| `--json PATH` | 标准空白模型 | UTF-8 JSON 模型表；最大 20 MiB；不能与 `--template` 同时使用 |
| `--timeout SECONDS` | `3700.0` | 最长等待时间，用于允许后端完成 Excel 解析 |
| `--api-token TOKEN` | 已配置 Token | 临时覆盖完整 Token |
| `--base-url URL` | 安装包对应环境地址 | 仅覆盖本次请求的后端地址 |

## JSON 输入格式

使用 `--json` 时，文件内容必须是下面结构中的模型对象：

```json
{
  "Component": [
    {"0": "Symbol", "1": "Unit", "2": "Name", "3": "Description"},
    {"0": "S_O2", "1": "gO2/m3", "2": "Dissolved oxygen", "3": null}
  ],
  "Parameter": [
    {"0": "Symbol", "1": "Unit", "2": "DefaultValue", "3": "LowerBound", "4": "UpperBound", "5": "Name", "6": "Description"},
    {"0": "k", "1": "/d", "2": 0.1, "3": 0, "4": 1, "5": "Rate coefficient", "6": null}
  ],
  "Matrix": [
    {"0": "Name", "1": "S_O2", "2": "Rate"},
    {"0": "Removal", "1": "-1", "2": "k*S_O2"}
  ],
  "Composition": [],
  "Ionization": []
}
```

`Component`、`Parameter`、`Matrix` 必填；`Composition` 和 `Ionization` 可选。
`Balance` 是只读派生表，创建 JSON 时禁止提交。后端会根据 `Matrix` 和
`Composition` 自动计算它；CLI 和后端都会拒绝包含 `Balance` 的请求。如果复用
`get-biomodel` 返回的 JSON，提交前必须删除其中的 `Balance` 字段。JSON 导入仍
使用与 Excel 导入相同的 BioModel 解析器校验表头、公式、符号和矩阵一致性，成功时返回
`creationMode: "json"`。

后端解析完成后会删除临时上传文件，数据库保存解析后的模型而不是原始 Excel。
解析前会确认上传内容是未加密的有效 `.xlsx` 工作簿，并将解压后总大小限制为
100 MiB。
Token 缺失、没有 `write` scope、名称重复（`HTTP 409`）、模板无效、解析超时
（`HTTP 504`）或后端无法创建模型时，命令会以非零状态码退出，并将安全错误
信息写入 stderr。

## 返回结果

成功时，stdout 输出包含 `success: true`、新 BioModel 的 `id`、名称、Draft 元数据、
描述和 `sourcepaperId` 的 JSON：

`creationMode` 为 `blank`、`template` 或 `json`；四个 amount 字段用于确认解析后的
模型规模。没有提供来源论文时，`sourcepaperId` 返回 `null`。

```json
{
  "success": true,
  "id": 1234,
  "name": "MyModel",
  "state": "Draft",
  "privacy": "Private",
  "version": 0,
  "creationMode": "blank",
  "description": "",
  "sourcepaperId": null,
  "amountParameter": 4,
  "amountComponent": 3,
  "amountRate": 2,
  "amountComposition": 1
}
```
