# `get-project-variables`：读取 Variable 全部字段

读取当前 Token 用户所拥有 Project 的完整 `Variable` 表。命令会返回原始
字段名和每一行的完整内容，而不是只返回 `Value`。

## 使用条件

- Token scope：`read`
- `PROJECT_ID`：当前 Token 用户拥有的正整数 Project 数据库 ID

系统不会枚举其他用户的 Project。无权访问或不存在的 Project 都会返回
`HTTP 404 Project not found`。

## 命令格式

```text
simpo get-project-variables PROJECT_ID [OPTIONS]
```

示例：

```text
simpo get-project-variables 706
```

## 选项

| 选项 | 默认值 | 作用 |
| --- | --- | --- |
| `--timeout SECONDS` | `10.0` | HTTP 请求的最长等待时间 |
| `--api-token TOKEN` | 已配置 Token | 临时覆盖完整 Token |
| `--base-url URL` | 安装包环境对应的地址 | 仅覆盖本次请求的后端地址 |

## 返回结果

JSON 包含 Project 信息、`columns` 数组和 `variables` 数组。每一项都是按返回
字段名组织的完整数据行。标准字段包括：

| 字段 | 含义 |
| --- | --- |
| `Variable` | Variable 名称 |
| `Tank` | 所属 Tank；全局 Variable 为 `null` |
| `Value` | 当前数值 |
| `Evaluation` | 是否参与 Evaluation |
| `InitialValue` | 计算使用的初始值 |
| `DecimalPoint` | 显示/精度设置 |
| `LowerBound` | 闭区间下限 |
| `UpperBound` | 闭区间上限 |

`Variable` 和 `Tank` 是只读定位字段。查询结果会保留它们，方便脚本准确定位
数据行，但 `set-project-variable` 不能修改它们。只有修改来源 BioModel 或
DataSet 的结构时，它们才会自动变化。

后端未来可能增加字段。自动化程序应使用 `columns` 判断字段，不要假设上述
标准字段列表永远固定。

脚本可以只解析 stdout：

```bash
variables="$(simpo get-project-variables 706)" || exit $?
printf '%s\n' "$variables"
```

修改单个可写字段请使用
[`set-project-variable`](./set-project-variable)。
