# 在 Codex 中使用 SimpoCLI Skill

需要完整工作流时，请明确调用 `$simpo`。Skill 名称保持英文，后续提示词
可以使用中文或英文。

## 只读示例

```text
请使用 $simpo 列出所有名为 ASM1 的 BioModel，并读取最新版的完整模型表，不要修改任何内容。
```

```text
请使用 $simpo 查看 Project 706 的全部 Variable，并汇总 Evaluation=true 的参数，不要修改数据。
```

Skill 会直接执行请求的命令；SimpoCLI 与后端负责认证、归属和 scope 校验。按名称查找
时它会遍历全部分页，并解析 JSON 输出。只有命令报错、语法不清或用户询问身份/scope
时，才读取 `--help` 或运行 `simpo me`。

## 写操作示例

```text
请使用 $simpo 将 Project 706 中 AnoxicTank 的 S_O2 Variable 的 LowerBound 改为 0.1。执行前先展示当前行和计划修改。
```

如果只是询问“`set-project-variable` 如何使用”，Skill 只会解释命令，不会执行更新。

## 计算示例

```text
请使用 $simpo 检查 Project 706，按当前安装版本的默认参数启动 SIM 计算，等待终止状态并报告结果。
```

Skill 会区分“准备并启动成功”和“计算完成”。除非明确的集成任务需要，否则不会
输出包含短期凭证的启动协议。

## BioModel 发布示例

```text
请使用 $simpo 检查 BioModel 123。如果它是我的 version 0 Draft，就创建 Private Release，并验证返回的 Release ID 和 version。
```

需要 `Public` 时必须明确提出。Skill 默认使用 Private，并在发布前确认确切目标。

## 安装版本差异

如果请求的命令不可用或被拒绝，应报告 CLI/后端错误，并在适当时建议升级 SimpoCLI；
不会绕过 CLI 自行构造 OpenAPI 请求。
