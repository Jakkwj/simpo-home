# `create-dataset`：新建 Draft DataSet

新建属于当前用户的 Private、version `0` Draft DataSet。不传 `--json` 时，后端
创建并解析标准空白 DataSet；传入 `--json` 时，在同一次创建操作中解析完整 detail。

## 使用条件

- Token scope：`write`
- 名称为 1 至 230 个字符，且不能与当前账户的 Draft DataSet 重名。
- JSON 必须包含 `Unit`、`Target`、`Tank`、`Pump`、`Measured`、`Inflow`、
  `Flow` 和 `Connection` 数组。
- `Unit`、`Target`、`Tank`、`Connection` 必须包含表头；其余四张表可以是空数组。

## 命令格式

```text
simpo create-dataset NAME [--json DETAIL.json] [OPTIONS]
```

示例：

```text
simpo create-dataset InfluentData
simpo create-dataset InfluentData --json ./DataSet.json
```

常用选项包括 `--description`、`--sourcepaper-id` 和 `--timeout`；通用请求选项包括
`--api-token TOKEN` 和 `--base-url URL`。
