# `me`：验证当前 API Token

使用 `me` 确认 SimpoCLI 可以正常认证，并查看当前 Token 对应的用户、
Token ID 和 scopes。

## 使用条件

- 已配置 Token，或通过 `--api-token` 提供完整 Token。
- Token 必须具有 `read` scope。

## 命令格式

```text
simpo me [OPTIONS]
```

执行 [`configure`](./configure) 后通常直接运行：

```text
simpo me
```

临时使用另一个 Token，而不修改本地文件：

```bash
simpo me --api-token "$SIMPO_API_TOKEN"
```

## 选项

| 选项 | 默认值 | 作用 |
| --- | --- | --- |
| `--timeout SECONDS` | `10.0` | HTTP 请求的最长等待时间 |
| `--api-token TOKEN` | 本地保存的配置 | 临时覆盖完整 Token |
| `--base-url URL` | 安装包环境对应的地址 | 仅覆盖本次请求的后端地址 |

Token 查找顺序为 `--api-token`、`SIMPO_API_TOKEN` 环境变量、本地 JSON
文件。

## 返回结果

结果只包含身份和权限，不包含 Token 原文：

如果返回 `401`，说明当前 Token 不被所选后端接受。认证成功也不代表所有命令
都有权限，应根据后续操作检查是否具有 `read`、`write` 或 `calculate` scope。

```json
{
  "userId": 123,
  "tokenId": 7,
  "scopes": ["read", "write", "calculate"]
}
```
