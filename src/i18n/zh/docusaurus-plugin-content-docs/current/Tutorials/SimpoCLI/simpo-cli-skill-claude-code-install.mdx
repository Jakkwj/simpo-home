# 在 Claude Code 中安装 SimpoCLI Skill

## 使用 SimpoCLI 安装和更新

SimpoCLI **0.1.8 起**支持以下命令；旧 CLI 需要先下载安装新版。

```bash
simpo skills install simpo --target claude
simpo skills update simpo --target claude --check
simpo skills update simpo --target claude
```

安装 Project 会补齐另外三项依赖。省略名称时安装全部四项，更新命令更新已安装的
Skills。四项共用 `0.1.8-skills.1` 这样的版本，后缀独立递增。已有手工安装或本地
修改时默认停止覆盖；加 `--force` 会先备份，并返回备份目录。完成后开启新的助手会话。

这是个人目录安装，调用名为 `/simpo`、`/simpo-create-project` 等。若已通过
Marketplace 安装插件，请继续使用 Claude 插件管理器更新；CLI 会拒绝重复安装，
不会修改插件缓存。插件仍使用 `/simpo:simpo` 等命名空间调用。

Claude Code 的 `simpo` 插件与 Codex 直接安装版本共用同一个 `simpo` Skill 和参考资料。
它通过当前安装的 SimpoCLI 操作 SIMPO，不包含 API Token。

所有 Skill、调用名称和安装目录的对照请参阅 [Skill 总览](./simpo-skills)。

## 安装前准备

需要安装 Claude Code 和 SimpoCLI：

```text
claude --help
simpo --version
simpo --help
```

命令需要认证时，再在终端中交互配置 Token：

```text
simpo configure
```

不要把 Token 粘贴到 Claude 提示词中。

Marketplace 安装由 Claude Code 管理，插件缓存目录不是稳定的用户目录。如果不支持
插件，手工备用目录为 `~/.claude/skills/simpo`。

## 从 SIMPO Marketplace 安装

Claude Code 官方支持仓库 Marketplace。请在 Claude Code 交互会话中运行以下斜杠命令，
并按官方记录的 `owner/repo` 格式添加 GitHub 仓库：

```text
/plugin marketplace add Jakkwj/simpo-home
```

安装插件：

```text
/plugin install simpo@simpo
```

如果提示需要重新加载插件，请运行：

```text
/reload-plugins
```

带命名空间的 Skill 调用名为 `/simpo:simpo`。

## 验证

在新会话或重新加载后的会话中运行：

```text
/simpo:simpo 请说明这个 Skill 的作用，不要执行任何修改。
```

响应应说明它会直接调用 SimpoCLI、安全操作 SIMPO 资源并验证 JSON 结果。
下一步参阅 [Claude Code 使用方法与示例](./simpo-cli-skill-claude-code-usage)。

## 更新

刷新 Marketplace，再更新插件：

```text
/plugin marketplace update simpo
```

然后打开 `/plugin`，进入 **Installed**，选择 `simpo@simpo` 并点击 **Update**；
如有提示则重新加载插件。

## 手工安装备用方案

如果当前 Claude Code 不支持插件，请先升级。临时本地安装时，将完整的
`plugins/simpo/skills/simpo` 目录复制到 `~/.claude/skills/simpo`；不能只复制
`SKILL.md`，因为工作流需要 `references/` 文件。此时调用命令为不带插件命名空间的
`/simpo`。
