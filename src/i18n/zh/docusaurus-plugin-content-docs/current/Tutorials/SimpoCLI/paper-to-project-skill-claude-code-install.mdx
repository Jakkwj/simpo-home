# 在 Claude Code 中安装

## 使用 SimpoCLI 安装和更新

SimpoCLI **0.1.8 起**支持以下命令；旧 CLI 需要先下载安装新版。

```bash
simpo skills install simpo-create-project --target claude
simpo skills update simpo-create-project --target claude --check
simpo skills update simpo-create-project --target claude
```

安装 Project 会补齐另外三项依赖。省略名称时安装全部四项，更新命令更新已安装的
Skills。四项共用 `0.1.8-skills.1` 这样的版本，后缀独立递增。已有手工安装或本地
修改时默认停止覆盖；加 `--force` 会先备份，并返回备份目录。完成后开启新的助手会话。

这是个人目录安装，调用名为 `/simpo`、`/simpo-create-project` 等。若已通过
Marketplace 安装插件，请继续使用 Claude 插件管理器更新；CLI 会拒绝重复安装，
不会修改插件缓存。插件仍使用 `/simpo:simpo` 等命名空间调用。

安装包含 SIMPO Project 和其他 SIMPO Skill 的插件：

```text
/plugin marketplace add Jakkwj/simpo-home
/plugin install simpo@simpo
```

插件加载后，调用命令为：

```text
/simpo:simpo-create-project
```

如果当前 Claude Code 版本无法安装插件，可将完整目录
`plugins/simpo/skills/simpo-create-project` 复制到：

```text
~/.claude/skills/simpo-create-project
```

手工安装时，还需将同级的完整目录
`simpo`, `simpo-create-biomodel`, 和 `simpo-create-dataset`
复制到各自的 `~/.claude/skills/` 目录，保留 DataSet 的
`scripts/`。通过插件安装已包含这些依赖。

SimpoCLI 需要单独安装和配置。
