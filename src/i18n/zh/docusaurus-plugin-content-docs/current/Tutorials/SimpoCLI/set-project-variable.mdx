# `set-project-variable`：修改 Variable 字段

修改 version 为 `0` 的 Draft Project 中一个 Variable 字段。默认字段仍是
`Value`，因此原有修改数值的命令无需改变。

## 使用条件和校验规则

- Token scope：`write`
- Project 必须属于当前 Token 用户。
- 只能修改 Project version `0`。
- `VALUE` 必填，其语法由 `--field` 决定：
  - 数值字段使用有限 JSON 数值，例如 `95.8`；
  - `Evaluation` 使用 `true` 或 `false`；
  - 其他可写字符串字段使用普通文本。
- `Variable` 和 `Tank` 是只读定位字段。它们可以分别作为位置参数和
  `--tank` 用来定位数据行，但不能作为 `--field` 修改。应通过来源 BioModel
  或 DataSet 的结构修改流程改变它们。
- 标准可写字段包括 `Value`、`Evaluation`、`InitialValue`、`DecimalPoint`、
  `LowerBound` 和 `UpperBound`。后端也支持将来新增的 JSON 标量列，无需同步
  修改 CLI，但 `Variable` 和 `Tank` 始终例外。
- 修改 `Value`、`InitialValue` 或任一边界时，后端会重新校验整行，并保持
  `LowerBound <= Value/InitialValue <= UpperBound`。
- Tank 专属 Variable 使用 `--tank` 定位；全局 Variable 不要传该选项。

## 命令格式

```text
simpo set-project-variable PROJECT_ID VARIABLE VALUE [--tank TANK] [--field FIELD] [OPTIONS]
```

示例：

```text
simpo set-project-variable 706 S_O2 95.8 --tank AnoxicTank
simpo set-project-variable 706 S_O2 0.1 --tank AnoxicTank --field LowerBound
simpo set-project-variable 706 S_O2 false --tank AnoxicTank --field Evaluation
simpo set-project-variable 706 S_O2 3 --tank AnoxicTank --field DecimalPoint
```

以下命令会被拒绝，因为行身份字段是只读的：

```text
simpo set-project-variable 706 S_O2 X --field Variable
simpo set-project-variable 706 S_O2 NewTank --field Tank
```

Variable 和 Tank 名称用于定位已有数据行。建议先使用
[`get-project-variables`](./project-variables) 查看 Project。字段名称不区分
大小写，响应会返回表头中的规范名称。

## 选项

| 选项 | 默认值 | 作用 |
| --- | --- | --- |
| `--tank TANK` | 不传 | Tank 专属 Variable 所属的 Tank |
| `--field FIELD` | `Value` | 要修改的已有 Variable 字段 |
| `--timeout SECONDS` | `10.0` | HTTP 请求的最长等待时间 |
| `--api-token TOKEN` | 已配置 Token | 临时覆盖完整 Token |
| `--base-url URL` | 安装包环境对应的地址 | 仅覆盖本次请求的后端地址 |

## 成功和错误

成功 JSON 的 `success` 为 `true`，并包含 Project、Variable、字段、旧值、
新值以及当前上下界。非零退出码表示后端没有确认修改成功。

常见错误包括 Variable、Tank 或字段不存在、尝试修改只读的 `Variable`/`Tank`、
值类型错误、数值超出闭区间、Project version 不是 `0`、缺少 `write` scope
或 Project 不属于当前用户。
