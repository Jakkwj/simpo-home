# `get-project`：读取 Project 详情

读取当前用户拥有的一个 Draft 或 Release Project。Token scope：`read`。

```text
simpo get-project PROJECT_ID
```

响应包含当前用户拥有的 Project 元数据、Solution `detail`、引用的 BioModel 和
DataSet ID，以及结果元数据。较大的计算数据请使用
[`get-calculation-result`](./calculation-result) 单独读取。

`PROJECT_ID` 可以是 version `0` Draft，也可以是 version `> 0` Release。

Project 不存在或不属于当前 Token 用户时，后端会返回错误。

可用选项包括 `--timeout SECONDS`（默认 `10.0`）、`--api-token TOKEN` 和
`--base-url URL`。
