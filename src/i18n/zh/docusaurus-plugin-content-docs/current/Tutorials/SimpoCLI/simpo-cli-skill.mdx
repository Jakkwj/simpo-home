# SimpoCLI Skill

所有 SIMPO Skill、Codex/Claude Code 调用名称和安装目录请参阅 [Skill 总览](./simpo-skills)。

SimpoCLI Skill 是供 AI 编码助手按需读取的操作指南。它让助手选择正确的
`simpo` 命令、保护 API Token，将认证和 scope 校验交给 CLI 与后端、审查会改变状态的
操作、解析 JSON 结果，并处理结果不确定的失败。

是的，它可以减少每次对话中重复输入的 token。Skill 采用渐进加载：

1. 平时只提供很短的名称和描述，用于判断是否应触发；
2. 触发后才加载核心 `SKILL.md`；
3. 然后只读取当前任务所需的命令组资料，例如 BioModel 或 Calculation。

因此不需要在每次对话中粘贴完整 CLI 说明书。调用 Skill 本身仍会占用一些上下文；
只有语法不清、命令报错或用户询问身份/scope 时才读取 `--help` 或运行 `simpo me`。
它减少的是重复且与当前任务无关的输入，并不是完全不消耗 token。

## 覆盖范围

Codex 和 Claude Code 提供相同的使用流程。Codex 调用名为 `$simpo`，
Claude Code 插件调用名为 `/simpo:simpo`。它包含：

- Token 配置、身份、scope、退出登录和 JSON 自动化；
- BioModel 新建、列表、读取、更新、同步和发布；
- DataSet 新建、列表、读取、更新、同步和发布；
- Project 新建、列表、读取、更新、同步、发布，以及 Project Variable 读取和更新；
- 计算准备、引擎选择、状态查询、停止和分页结果读取。

文档覆盖的公开顶层命令包括：
`configure`、`me`、`logout`、`create-biomodel`、`update-biomodel`、
`sync-biomodel`、`release-biomodel`、`get-biomodels`、`get-biomodel`、
`create-dataset`、`get-datasets`、`get-dataset`、`update-dataset`、
`sync-dataset`、`release-dataset`、`create-project`、`get-projects`、
`get-project`、`update-project`、`sync-project`、`release-project`、`get-project-variables`、
`set-project-variable`、`calculate`、`get-calculation-status`、
`get-calculation-result` 和 `stop-calculation`。

这里指的是 Skill 的覆盖范围，不代表旧版已安装程序一定提供全部文档命令。实际执行的
命令及后端响应才是最终依据；如果命令不存在，会报告错误并可能需要升级 SimpoCLI。

此 Skill 负责操作 SimpoCLI，不包含 SimpoCLI 安装包或 API Token。它也不替代专用的
BioModel Skill；后者用于分析研究论文并推导模型表格。

## Python 和 Poppler

SimpoCLI Skill 和普通 `simpo` 命令不要求 Python 或 Poppler。如果 DataSet 或 Project
论文流程需要渲染 PDF 图片，配套 Skill 会检查 Python 3 和 Poppler 的 `pdftoppm`；提供
页码范围时 `pdfinfo` 可不安装。文字、表格、用户提供的图片和数字化导出文件不需要这些工具。

## 安全边界

- 以当前安装的 SimpoCLI 及后端响应为准，由它们负责命令可用性、认证、归属、参数和
  scope 校验。
- Token 通过 `simpo configure` 的隐藏输入配置，不能粘贴到 AI 对话中。
- 只询问说明不会授权执行写操作。
- Public 发布、开始/停止计算以及其他重要写操作需要先确认目标和影响。
- 写操作超时后先查询当前状态，再决定是否重试，避免重复创建、发布或计算。
