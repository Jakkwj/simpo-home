# Project

Project 用于将一个 BioModel 与一个 DataSet 连接起来，并配置模拟、敏感性分析、不确定性分析和参数估计所需的求解与计算设置。

## Project 页面结构

打开 Project 后，顶部菜单包括：

- `Detail`：编辑 Project 的 `Solution`，并打开关联的 BioModel 和 DataSet。
- `Calculation`：配置并启动计算，查看计算结果。
- `Version`：将 Draft 发布为按数字递增的版本。
- `Profile`：查看描述、论文、关联的 BioModel 和 DataSet，以及被引用的对象。

`Detail` 左侧菜单包含 `Solution`、`BioModel` 和 `DataSet`；`Calculation` 左侧菜单包含 `Console`、`Simulation`、`Sensitivity`、`Uncertainty` 和 `Estimation`，其中后四项在对应结果生成后显示。

请先阅读[新建](./Project/Create)，再阅读[编辑](./Project/Edit)了解各字段和计算流程。
