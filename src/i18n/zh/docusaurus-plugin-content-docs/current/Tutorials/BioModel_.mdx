# BioModel



BioModel 是您建立自己的生化模型的地方。

## <a id="Detail"></a>Detail

BioModel 包含了 Components，Parameters，Compositions，Ionization 和 Processes 等组件。
在 BioModel 的 Detail 页面中可以查看和编辑它们。


### <a id="Components"></a>1. Components

Components 是模型的组分，是模型模拟计算的主要对象，通常包括各种溶解态（Soluble）和颗粒态（Particulate）的基质和微生物。

- Components 组件弹窗中可以查看和编辑组分的详细信息：
  - 具体内容包括命名符号，单位，单位，名称，描述。
  - 组分可以进行新建，复制，删除，移动排序操作。
  - 可以通过 ctrl/shift + 鼠标左键选择多个组分进行批量操作。
- 组分的命名符号（Symbol）只能由英文字母，数字和下划线（下划线不能连续）组成。
- Soluble 组分必须以 “S_” 为前缀进行命名，如 溶解氧（DO） 应命名为 S_O2。
- Particulate 组分必须以 “X_” 为前缀进行命名，如 普通异养菌（OHO） 应命名为 X_OHO。
- Soluble 组分 和 Particulate 组分在沉淀行为上有不同的特性。
- 组分的单位会显示在计算结果的图片中。
- 保存时，会自动把 Soluble 组分放在 Particulate 组分的前面。


### <a id="Parameters"></a>2. Parameters

Parameters 是模型中使用的参数，通常包括各种化学计量学参数（Stoichoimetry）和动力学参数（Kinetic）和常数，是调参 （Parameter Estimation）的主要对象。

- Parameters 组件弹窗中可以查看和编辑（新建，复制，删除，移动排序）组分的详细信息，包括组分的命名符号，单位，默认值，取值下限，取值上限，名称，描述等。
- 参数的命名符号（Symbol）只能由英文字母，数字和下划线（下划线不能连续）组成。
- 参数必须以字母为开头。
- 单位：
  - 如果参数是动力学参数，其单位**必须以**：``/d``, ``d-1``, ``/day``, ``day-1``, ``1/d``, ``1/day``, ``/h``, ``h-1``, ``/hour``, ``hour-1``, ``1/h``, ``1/hour``, ``/m``, ``m-1``, ``/minute``, ``minute-1``, ``1/m``, ``1/minute``, ``/s``, ``s-1``, ``/second``, ``second-1``, ``1/s`` or ``1/second`` 为结尾，这样才能保证整个计算过程中时间单位的统一。
  - 比如某动力学参数 `u_max` 的默认值为 `10 /d`， 则可以输入：
    - `DefaultValue` 为 `10`，`Unit` 为 `/d`（或者 ``d-1``, ``/day``, ``day-1``, ``1/d``, ``1/day``）。
    - 或者 `DefaultValue` 为 `10/24`，`Unit` 为 `/h`（或者 ``h-1``, ``/hour``, ``hour-1``, ``1/h``, ``1/hour``）。
    - 或者 `DefaultValue` 为 `10/24/60`，`Unit` 为 `/m`（或者 ``m-1``, ``/minute``, ``minute-1``, ``1/m``, ``1/minute``）。
    - 或者 `DefaultValue` 为 `10/24/60/60`，`Unit` 为 `/s`（或者 ``s-1``, ``/second``, ``second-1``, ``1/s``, ``1/second``）。
    - 动力学参数的单位以这些为结尾即，即 `/d` 与 `mgCOD/d` 效果相同。


- 组分的单位会显示在计算结果的图片中。

### <a id="Compositions"></a>3. Compositions
- Compositions 用于检查模型的各物质平衡，通常包括 ThOD，N，P，S，Charge 和 TSS 平衡。

### <a id="Ionization"></a>4. Ionization
- Ionization 用于描述 Components 在水中的电离状态，用于 pH 计算。

### <a id="Processes"></a>5. Processes
- Processes 用于描述模型中发生的各种生化过程，通过矩阵（Matrix）的方式进行描述，矩阵的行是 Processes，列是 Components（除最后一列），矩阵中的元素是各个组分在各个过程中的化学计量学参数（Stoichoimetric），最后一列是每个 Processe 的速率方程。
