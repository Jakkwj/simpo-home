BioModel 是您建立自己的生化模型的地方。


创建 BioModel 有几种方法（从下面的 6 种方法中选择一种）：

## <a id="way_1"></a>1. 空白新建

创建一个空的 BioModel，编辑并保存后使其生效。
- 添加新 Components。
- 添加新 Parameters。
- 添加新 Processes（在 Matrix 中）。

## <a id="way_2"></a>2. 在 Project 新建时同时新建

如果在创建新 Project 时没有指定 BioModel，则会相应地创建一个空的 BioModel。
