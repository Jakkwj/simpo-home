# 编辑控制器

控制器通过调节一个输入量，让一个工艺指标维持在设定值附近。例如，希望 Tank5 的溶解氧保持在 2 g O₂/m³，便可让传感器读取 Tank5 的溶解氧，读数偏低时由 PI 控制器提高曝气强度。在 DataSet 中定义在哪里测、测什么、按什么参数控制、调节哪个输入。要看到工艺怎样响应，再到包含生化模型和运行条件的 Project 中试调。

## 新建和接线 {#connect}

1. 打开可编辑 DataSet 的流程图。先建立测量位置（池体或进水口）、水质**指标（Target）**，以及要调节的**流量（Flow）**。给该 Flow 填写至少一条时刻 0 的数值。若要直接调节氧传递系数，将 KLaPump 用这个 Flow 连到接收曝气的 CSTR。
2. 选择**新建控制器**，把鼠标移到 PI 卡片上可看到四侧的端口。将测量位置连到一个端口，再从端口拖到要调节的 Flow 或 KLa 标签。两条线可以先后任意连接。端口所在的边决定线在图上的走向，每个控制器接收一个测量值、发出一个控制指令。
3. 在**列表 → 控制器**中点控制器名称打开详情。也可直接在详情里选择**测量位置、测量指标、操纵量**。将**控制器名称**改成容易识别的唯一名称，例如 `Tank5_DO_PI`。改名后原连线仍有效。如果更换已保存参考回路的测点、指标或操纵量，请在「替换连接」时核对重新初始化后的设置。
4. 按下面三个页签填写，点**应用**，再在 DataSet 页面点**解析（Parse）**校验并保存。新控制器的 PI 参数还没填全时，可以**保存为待整定草稿**。补齐并应用后，它才会在模拟中参与反馈控制。

每个操纵量只能由一个控制器调节。例如 `Q_a` 是一个可独立调节的 Flow，`Q_0+Q_r` 是两股流量的和。若要调节其中的回流，应连接到 `Q_r`。流程图的**工具 → 信号**可以显示或隐藏绿色控制线。

## 传感器 {#sensor}

| 字段 | 怎样填写 |
| --- | --- |
| **测量位置** | 选择传感器所在的池体或进水口。测沉淀池时，选择具体的出水区、泥层区或 Takacs 池的编号层。第 1 层在池底。 |
| **测量指标** | 选择 DataSet 在该位置的 Target，例如 Tank5 的 `S_O2`。模拟运行时，传感器读取当前工艺值。「实测（Measured）」序列用于对照模拟结果。 |
| **量程下限、量程上限** | 按指标的单位填写仪表可报告的最小值和最大值，上限须大于下限。超出量程的读数取相应边界值。下限默认为 0，可以修改，例如 pH 探头可设为 5–9。 |
| **传感器预设** | 根据下表选择响应速度和采样方式。量程和噪声另行设置。 |
| **噪声来源** | 选**关闭**得到无噪声读数。选**随机**可生成一组可重复的噪声。选 **BSM1** 则逐分钟重放模拟第 0–14 天的参考噪声。超过第 14 天时选关闭或随机。 |
| **噪声标准差、噪声更新时间间隔、随机种子** | 选择「随机」后显示。标准差为正，单位与测量指标相同，默认取量程宽度的 2.5%（量程 0–10 时为 0.25）。更新间隔须为正，默认 1 分钟。程序生成整数种子，保留它可重现相同的噪声，改动它可生成另一组。 |

| Dash 中的预设 | 指标突然变化时如何响应 | PI 多久收到一个新读数 |
| --- | --- | --- |
| BSM Class A | 两级滞后，1 分钟跟上变化量的 90% | 连续更新 |
| BSM Class B0 / B1 | 八级滞后，10 分钟跟上 90% | B0 连续更新。B1 每 5 分钟更新一次，期间保持上次读数。 |
| BSM Class C0 / C1 | 八级滞后，20 分钟跟上 90% | C0 连续更新。C1 每 5 分钟更新一次，期间保持上次读数。 |
| BSM Class D | 每 30 分钟采样，再延迟一个采样周期 | 每 30 分钟更新一次。第 0 分钟的样本在第 30 分钟送给 PI。 |

例如 Class A 探头最初读 2 g O₂/m³，实际溶解氧突然升到 4 并保持，关闭噪声时，1 分钟后约读 3.8。在这一分钟**以内**读数也在变化。在**固定参数**可查看实际生效的响应时间、采样方式和初值。已有基准案例还可能保存理想传感器的响应与初态。[传感器计算原理与算例](./Edit.mdx#sensor)

## PI 控制器 {#pi}

| 字段 | 怎样填写 |
| --- | --- |
| **设定值** | 填希望维持的测量值，单位与 Target 相同，取值在传感器量程内，含上下限。BSM1 溶解氧回路填 2 g O₂/m³。 |
| **比例增益** | 描述偏差每变化一个单位，指令中的比例项改变多少，带正负号。单位为操纵量单位除以测量指标单位。控制器名称下方的提示会用当前指标、单位和方向说明实际作用。 |
| **积分时间** | 填大于 0 的**天数**，即使 DataSet 的时间轴是小时也一样。偏差持续存在时，积分时间越短，累积修正越快。BSM1 溶解氧回路填 0.002 d，即 2.88 分钟。 |
| **跟踪时间** | 填大于 0 的**天数**。指令超过执行器上下限时，此值决定抗积分饱和修正把内部指令拉回可执行范围的速度。溶解氧回路填 0.001 d，即 1.44 分钟。 |

新建 PI 预填比例增益 1、积分时间 1 d、跟踪时间 0.5 d，供首次试调。编辑器也会参考首个可用测量值及已有序列的峰值预填设定值和上限。应按控制目标和设备能力核对这些值。展开**固定参数**可查看偏置、积分初态、抗饱和初态以及抗积分饱和是否启用。

## 操纵量 {#handle}

BSM1 表 15 列出 28 项可操纵量，包括三股全厂流量、五个池的 KLa、五个外加碳源流量，以及十五个分配比例。原水、内回流和污泥回流各有五个分配比例，每组之和均为 1。默认策略只启用下图中的两项。[逐项查看上下限、单位和分流示例](../../CaseStudy/BSM1/Setup.mdx#control-handles)

![案例 04 控制器列表中的硝态氮–内回流、溶解氧–曝气两个回路。](/img/bsm1/dry-closed-controllers-zh.png)

| 字段 | 怎样填写 |
| --- | --- |
| **操纵量** | 选择需要调节的独立 Flow。水流量和 AirPump 的空气流量单位都是 **m³/d**。KLaPump 的输入（如 `KLa_5`）单位为 **d⁻¹**，上下限也用这一单位。 |
| **下限、上限** | 填设备允许的最小和最大指令。下限须大于等于 0。需要试调时，应留出可调范围，使上限大于下限。两限相等时，指令固定在该值。 |

展开**执行器固定参数**可查看指令如何作用到工艺。理想执行器立即执行，带滞后的执行器会随时间跟上指令。这里列出响应时间、滞后阶数、初值和输入增益。闭环运行期间，工艺采用执行器实际施加的输出。DataSet 中仍应保留所选 Flow 及其起始数值。

**填写示例。** BSM1 动态溶解氧回路选择 Tank5、`S_O2`、**BSM Class A**，量程填 0–10 g O₂/m³，噪声选 **BSM1**。设定值填 2、比例增益填 25、积分时间填 0.002 d、跟踪时间填 0.001 d。操纵量选 `KLa_5`，两限填 0 和 360 d⁻¹。如果此刻传感器读 1.8，偏差就是 0.2 g O₂/m³，指令中的比例项为 **25 × 0.2 = +5 d⁻¹**。完整指令还包含偏置和控制器状态。若要复现参考曲线，请从已有闭环 Project 开始，以保留它的执行器响应和初始化条件。[BSM1 两个回路的实际设置](../../CaseStudy/BSM1/Setup.mdx#controller)

## 在 Project 中试调 {#trial}

打开使用此 DataSet 的**可编辑 Project**。试调要求项目从时刻 0 开始动态运行，使用**前向欧拉法**和恒容水力条件。保存工艺输入，再打开控制器的 **PI 控制器**页签，在输入覆盖的时间段内选择 6、24 或 72 小时的**试调时长**。

- **试调（Run trial）**检验已填写的 PI 参数。只想估算其中一项时，将该项留空，其他项保留。
- **估算全部 PI 参数**对三项都重新估算。SIMPO 先固定输入，让工艺达到稳定工况，再对操纵量施加阶跃、拟合测得的响应。比例增益和积分时间使用 Skogestad 的 SIMC 方法估算，跟踪时间由 SIMPO 单独推算。候选参数还要回到原来的动态输入上验证。若阶跃响应太弱，可能得不到候选值。[SIMC 公式、来源与试调案例](../../CaseStudy/BSM1/Setup.mdx#controller-trial)

图中的**已保存 PI**与**试调**分别使用保存的整定参数和本次填写或估算的参数，两者使用相同的当前设定值和项目输入。全新控制器的基线将操纵量保持在起始运行值。看上图可比较工艺指标与设定值，看下图可检查操纵量的实际变化。**工艺值的平均绝对偏差**按时间平均工艺值偏离设定值的大小，**操纵量累计变化量**累计实际输出每次变化的绝对量，**触限时间占比**给出指令限幅或实际输出处于上下限的时间比例。要保留候选参数，依次点**采用估算值、应用**，再保存 Project。
