# 编辑工艺评估指标

如果想知道“上周平均每天排出了多少千克 COD”，需要同时指定**出水流量、出水 COD 浓度和评价时段**。在 DataSet 的**流程图 → 列表 → 评估（Assessment）**中，每行定义一个这样的问题。关联该 DataSet 的 Project 运行动态模拟后，每项得到一个数值。

## 填写第一项指标 {#first-metric}

以下用一座已经建有末端池 `Eff`、水质 Target `COD` 和出水 Flow `Qe` 的厂举例。实际操作时，请从自己 DataSet 的候选列表选择相应名称。打开可编辑的草稿，点击**自定义指标**。

| 弹窗字段 | 示例 | 怎样填写 |
| --- | --- | --- |
| 指标（Metric）* | `EffCODLoad` | 填唯一的名称。后续公式可用这个名称引用结果。 |
| 单位（Unit）* | `kg COD/d` | 填计算结果的单位。单位栏用于显示，所需的数值换算写进公式。无量纲指标可填 `-`。 |
| 起始日（Start Day） | `7` | 评价开始的模拟日，留空取动态结果的起点。即使项目横坐标为小时，此处仍填天数。 |
| 结束日（End Day） | `14` | 评价结束的模拟日，须晚于起始日且在模拟结果覆盖范围内。两项都留空时用全程。 |
| 公式（Formula）* | `Mean(Qe * Eff.COD / 1000)` | 输入 `Mean`、流量名或池名，用 ↑、↓ 和 Enter 插入候选项，补上括号和运算符。整条公式应得出一个数值。 |

在这个例子里，流量单位为 m³/d，COD 浓度单位为 mg/L（数值等于 g/m³）。两者相乘得到 g COD/d，除以 1000 得到 kg COD/d，再按时间求平均。假设一天内前 6 小时为 100 m³/d、80 mg/L，后 18 小时为 200 m³/d、50 mg/L，两个时段的排放速率分别为 8 和 10 kg COD/d。这一天的平均值是 **(8 × 6 + 10 × 18) / 24 = 9.5 kg COD/d**。若要计算整个评价时段的排放总量，将 `Mean` 换成 `Integral`，单位填 `kg COD`。若连续七天重复上述工况，总排放量就是 **66.5 kg COD**。

点击**应用**，再用 **Parse（解析）** 校验并保存 DataSet。在 Project 内编辑时保存 Project。运行该项目的**计算 → 模拟**，从报告工具栏**平衡分析**右侧打开**评估**。点击指标名称可展开公式，逐项核对结果、单位和实际评价时段。修改公式后重新模拟，才能得到按新定义计算的结果。

## 公式里可以选择什么 {#signals}

引用会作为一个彩色标签插入。拼写和大小写必须与编辑器一致。

| 想读取的量 | 示例 | 含义 |
| --- | --- | --- |
| 某个位置的水质 | `Eff.COD`、`Tank6_10.TSS` | 前半部分选实际位置，后半部分选 Target。计算沉淀池出水时，选与出水连接对应的区或层。 |
| 独立的流量或 KLa 输入 | `Q_w`、`KLa_5` | 读取模拟中实际施加的命名信号。水流和空气流量用 m³/d，KLaPump 的输入用 d⁻¹。 |
| 池或沉淀层的体积 | `Tank1.Volume`、`Tank6_1.Volume` | 单位 m³。例如 `Change(Tank1.Volume * Tank1.TSS / 1000)` 计算该池期末相比期初增减的污泥质量（kg，TSS 以 g/m³ 计）。 |
| 池内实际氧传质系数 | `Tank5.KLa` | 合计该池所有曝气泵的贡献，计入配置的温度修正，单位 d⁻¹。想看泵的指令或输入时，选对应的命名信号。[两类曝气泵](./Pumps.mdx) |
| 两个端点之间的实际水流 | `Branch("Tank6_10", "Outflow")` | 第一个参数是起点，第二个是终点，同向平行连接会合计。工艺中至少一座 CSTR 启用混合进水滞后时，才记录并提供这些支路信号。 |
| 已定义的评估结果 | `5 * SP + AE + PE + 3 * EC + ME` | 先填写各分项，再引用它们的指标名。各项须使用同一评价时段，且相互引用不能成环。选择与 Flow 不同的名称便于直接引用。 |

在独立 DataSet 中用 Target 表示水质。进入已关联 BioModel 的 Project 后，候选列表还可以包括该模型的组分。

| 函数 | 如何使用 |
| --- | --- |
| `Mean(x)`、`Integral(x)` | 前者按时间取平均，后者按天积分。相邻两个已保存结果点之间采用左端值。 |
| `First(x)`、`Last(x)`、`Change(x)` | 分别取评价时段的期初值、期末值及期末减期初的差。 |
| `Change(x, -1)` | 期末向前取一条已保存的结果记录，再减去期初值。第二个参数填整数，如 `0`（与 `Change(x)` 相同）、`-1` 或 `-2`。超出本时段可回退的记录数时，该指标提示错误。 |
| `Min(x)`、`Max(x)` | 一个参数时取全时段极值。两个参数时逐点比较，例如 `Mean(Max(Eff.COD, 30))`。 |
| `If(条件, 满足时的值, 其余情况的值)` | 逐点判断。例如 `100 * Mean(If(Eff.COD > 50, 1, 0))` 得到 COD 高于 50 mg/L 的时间占比，单位填 `%`。 |

## 常用指标与 BSM1 预设 {#presets}

**常用指标**提供 EQ（出水水质）、SP（待处置污泥）、AE、PE、ME（曝气、泵送、搅拌能耗）、EC（外加碳源）和 OCI（运行成本指数）。普通污水厂可只选需要的几项，编辑器预填名称和建议单位；公式要按本厂的排放边界、设备功率或投加记录填写。例如，确认没有外加碳源时 EC 可以填 `0`。如果投加量未知，可稍后补充这项。

当池体、流量、曝气泵、连接、Target 及单位与标准 BSM1 布局匹配时，界面还会显示**添加 BSM1 七项指标**。该按钮补齐缺项并带入默认 ASM1 系数及第 7–14 天窗口，保留已有的同名定义。此布局下单独添加 OCI 也会补齐它引用的成本分项。复现 500 天恒定进水案例时，将各项窗口统一改成 493–500 天。七项公式和已计算的结果可在案例中逐项核对。[BSM1 评估实例](../../CaseStudy/BSM1/Assessment.mdx#run)

如果结果提示评价时段越界，请对照**动态结果**的起止时间。若某项提示找不到信号，核对连接的方向、层号和 Target。若单独输入 `Eff.COD`，得到的是一条时间序列，可按要回答的问题选 `Mean(Eff.COD)`、`Max(Eff.COD)` 或其他汇总函数。
