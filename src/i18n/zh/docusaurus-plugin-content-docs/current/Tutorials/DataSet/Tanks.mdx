**CSTR** 表示完全混合池，流出水的浓度等于池内浓度。如果需要区分沉淀池不同深度的水质，例如比较澄清出水和底部回流污泥的悬浮固体浓度，请选 **Takacs Settling**。打开 DataSet 草稿的**详情**，在流程图选择**新建池体**，也可以打开**列表 → 池体**并点 **+**。点击池体打开详情，编辑后关闭弹窗，再点**解析保存（Parse）**校验并保存 DataSet。

## CSTR 字段 {#cstr}

选**新建池体 → CSTR**，再打开池体。溶解氧饱和模型和饱和值保存在接收池的 `SaturationModel` 和 `SaturationValue` 字段中。

| 字段 | 含义与填写方法 |
| --- | --- |
| 名称（Name） | 填唯一名称，如 `Tank3`。以字母开头，可用字母、数字和不连续的下划线。连接、观测和公式通过这个名称定位池子。 |
| 体积（Volume，m³） | 填模拟开始时池内实际的水量。例如 BSM1 的 Tank3 填 **1333**。初始为空的变容池可填 0。 |
| 生化计算（BioCalculated） | 需要在该池计算 Project 的 BioModel 反应时开启。只考虑混合和输送的池子可关闭。 |
| 恒定体积（Constant Volume） | 水量保持固定时开启，并使进出池的液体流量平衡。需要模拟充水或排水时关闭，进出流量之差随时间累积为池容变化。 |
| 曝气器数量（Diffuser Number） | 使用 AirPump 时填实际分摊风量的水下曝气器个数，取非负整数。 |
| 曝气器深度（Diffuser Depth，m） | 使用 AirPump 时填曝气器在水面以下的深度。由风量计算氧传递时，数量和深度都要大于 0。直接使用 KLaPump 时，这两项可以填 0。 |
| α 系数（Alpha Factor） | 使用 AirPump 时，填污水与清水的传氧系数之比，范围 0–1。填 1 表示按清水传氧系数计算。 |
| β 系数（Beta Factor） | AirPump 配合**淡水**饱和模型时，填污水与清水的饱和溶解氧浓度之比，范围 0–1。例如 0.95 表示取清水饱和浓度的 95%。 |
| 溶解氧饱和模型（Oxygen Saturation Model） | 一般污水厂选**淡水**，复现 BSM2 选 **BSM2**，复现 BSM1 选**恒定**。[三种工况的填写方法与 β 修正](./Edit.mdx#do-temperature) |
| 饱和溶解氧浓度（Saturation Value，mg O₂/L） | 选**恒定**后填写，须为大于或等于 0 的有限数。BSM1 的曝气池填 **8**。这个值用于计算氧传递。如需控制池内 DO，目标值填在控制器的设定值字段。 |
| 混合进水响应（Mixed Inlet Response） | **即时混合**将所有液体进水的合计流量和各组分负荷立即送入池内。选**一阶滞后**后，送入池内的流量和负荷会逐步跟随来水变化。启用滞后的 Project 使用恒容水力条件和前向欧拉求解器。 |
| 时间常数（Time Constant，s） | 即时混合时显示 0。启用一阶滞后时填正数，单位为秒。进水流量突然改变并保持时，经过一个时间常数，实际送入池内的流量约完成这次变化的 63%。复现 BSM1 的 MATLAB 实现时，仅 Tank1 填 **8.64 s**，Tank2–Tank5 选即时混合。 |

**试填 BSM1 的 Tank5。** 体积填 **1333 m³**，开启生化计算和恒定体积，将饱和模型设为**恒定**，饱和浓度填 **8 mg O₂/L**。通过 `KLa_5` 连接 KLaPump。如果实际传氧系数是 **84 d⁻¹**，当时的池内 DO 是 **2 mg O₂/L**，则曝气对这一刻 DO 变化率的贡献为 **84 × (8 − 2) = 504 mg O₂/(L·d)**。后续池内 DO 还受生化反应和进出水影响。

新建 CSTR 时，SIMPO 会根据起点的来水和回流自动初始化。若在已有池体的**时间常数**旁看到**初始状态**按钮，可选**已保存的参考值**接续预运行，或选**起点混合进水**按当前来水启动。[BSM1 的 Tank1 设置](../../CaseStudy/BSM1/Setup.mdx#mixed-inlet)

下方选择**实测（Measured）**，按各 Target 的单位填水质记录，时间列使用 DataSet 的时间单位。时间 0 行记录起点观测，后续行填各时刻实际取得的测值。计算使用的起始组分浓度在 **Project → Solution → Variable** 中核对。作为初值约束的 Target 需要时刻 0 的测值。需要输入池内水温时切换到**环境（Environment）**，填写摄氏度序列 `T`。池子缺少水温序列时，温度型饱和模型采用 **20 °C**。[水温与饱和溶解氧计算](./Edit.mdx#do-temperature)

## Takacs 分层沉淀池字段 {#takacs}

1. 在**列表 → 指标（Targets）**找到代表总悬浮固体的 Target，将其 **StandardTarget** 选为 **Total Suspended Solids**。计算时需要唯一的 TSS 指标，并在 Project 的 **Solution → Conversion** 中配置如何由 BioModel 组分得到 TSS。
2. 复现 BSM1 时，从**新建池体 → Takacs Settling → 10 层**创建。其他工程可选 **3–10 层**，各层等厚。层数在新建时确定，以后可以调整面积、水深和进水层，层数保持只读。
3. 在池体详情中填写几何和沉降参数。下表给出 BSM1 十层池的数值。模拟其他沉淀池时按实际运行尺寸填写，沉降参数选用能描述该厂污泥沉降试验的值。

| 字段 | 示例 | 含义与填写方法 |
| --- | ---: | --- |
| 名称 | `Tank6` | 命名规则与 CSTR 相同。每一层都可通过池名和层号定位。 |
| 生化计算 | 关闭 | BSM1 的沉淀池只算水力输送和沉降。如所建沉淀池还需计算 BioModel 中的生化反应，可开启。 |
| 恒定体积（Constant Volume） | `True` | 只读，模拟期间水深固定。导出时，`TakacsSettlerTank` 工作表的 `ConstantVolume` 列为 `TRUE`。导入时填写 `FALSE` 会报错。 |
| 面积（Area，m²） | 1500 | 填水面的水平面积，须为有限正数。计算中每层使用相同面积。 |
| 总高度（Height，m） | 4 | 填有效水深，须为有限正数。每层厚度等于总水深除以层数。 |
| 体积（Volume，m³） | 6000 | 只读，由面积 × 水深自动计算。需要改池容时改面积或高度。本例每层体积为 600 m³，层厚为 0.4 m。 |
| 层数（LayerCount） | 10 | 新建时选定。层号从下往上数，本例第 1 层是池底，第 10 层是池顶。 |
| 进水层（FeedLayer，自底向上） | 6 | 取 **2 至层数减 1** 的整数，使进水层上下各留至少一层。三层池只能从第 2 层进水。 |
| V0Max（m/d） | 250 | 各层固体沉降速度的上限。 |
| V0（m/d） | 474 | 双指数沉降公式中的速度系数。公式算出的速度再用 V0Max 限制，因此 V0 可以大于 V0Max。 |
| Rh（m³/g SS） | 0.000576 | 受阻沉降系数，描述高浓度污泥中颗粒受阻、沉降速度下降的程度。 |
| Rp（m³/g SS） | 0.00286 | 絮凝沉降系数，决定低浓度区的固体浓度怎样影响沉降速度。 |
| Fns | 0.00228 | 进水 TSS 中不可沉降的比例，填 0–1 的小数。若进水 TSS 为 3000 g SS/m³，本例的不可沉降浓度为 6.84 g SS/m³。 |
| Xt（g SS/m³） | 3000 | 澄清区的沉降通量切换阈值。接收沉降污泥的下一层浓度超过 Xt 时，相邻两层可传递的较小通量限制向下输送量。 |

六个沉降参数均须为非负有限数。程序检查推算的层高和层体积均为有限正数。流量增大或层厚减小时，前向欧拉求解器会按各层的水力与沉降条件限制内部时间步。[层厚、流速与时间步约束](./Edit.mdx#takacs-step)

**连接并检查各层。** 将上游反应池连到沉淀池入口，程序会将进水送到设定的进水层。BSM1 的**顶层** `Tank6_10` 接出水（Outflow），**底层** `Tank6_1` 接回流污泥和剩余污泥两条支路。打开池体详情，下方选择**实测**，在紧随其后的**层号**菜单选**第 10 层**录入或查看出水观测，选**第 1 层**查看底部污泥。把实际取得的观测填到采样深度对应的层。各层计算使用的起始组分浓度在 **Project → Solution → Variable** 中核对。流程图中的倒锥形表示层序，计算时每层的水平面积相同。[核对 BSM1 池体布局与运行结果](../../CaseStudy/BSM1/Setup.mdx)
