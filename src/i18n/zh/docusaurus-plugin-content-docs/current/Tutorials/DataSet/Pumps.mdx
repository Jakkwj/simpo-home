# 设置 AirPump 与 KLaPump

先看手里的数据是什么。**已知送往某池的空气体积流量**，选 **AirPump**，SIMPO 根据风量和曝气器性能计算传氧。**已知该池的容积氧传质系数**，选 **KLaPump**，直接给出参考 KLa。BSM1 公开案例采用后者。两种泵都在流程图上通过一条带名称的 Flow 连接到 CSTR。泵的连接只参与传氧计算，水量平衡使用液体连接。

| 要填写的位置 | AirPump 示例 | KLaPump 示例 |
| --- | --- | --- |
| 泵详情 | 曝气器效率曲线系数和温度系数 | 温度系数和参考温度 |
| Flow 时间序列 | `Qair`，9,600 m³/d | `KLa_5`，84 d⁻¹ |
| 接收 CSTR | 曝气器数量、深度、α、β 和饱和溶解氧模型 | 饱和溶解氧模型。直接给定 KLa 时，传氧计算跳过曝气器参数和 α、β |

## 在流程图中创建并连接 {#connect}

1. 在 DataSet 草稿的 **Detail → 流程图** 中，选 **新增 → New Pump**，再选 **AirPump** 或 **KLaPump**。新泵直接出现在图上。用列表菜单的 **Pumps** 打开汇总表，点击泵名进入相应的详情。
2. 在 **Name** 填唯一设备名，例如 `Air_1` 或 `KLaPump5`。以英文字母开头，后面可用字母、数字和单个下划线。按下文填写该类型的字段，再点击**应用**。
3. 使用 **New Flow** 建立一个独立时间序列。时间按 **Unit → Time** 填写。AirPump 的**数值**用 m³/d，KLaPump 的数值固定用 d⁻¹（/d），即使时间轴选了小时也一样。停曝填 0。
4. 在 **Connections** 增加一条连接，依次选 `From`（泵）、`Flow`（刚建的序列）、`Into`（接收的 CSTR）。也可从泵的端点拖到池体，再为连接指定 Flow。KLaPump 连接须直接引用一个命名序列，例如 `KLa_5`。水流或风量另用各自的序列。
5. 在 **Targets** 将溶解氧指标（如 `S_O2`）的 **StandardTarget** 设为 **Dissolved Oxygen**。点击 **Parse（解析）** 校验并保存。计算 Project 时，将此 Target 映射到 BioModel 的氧组分；KLaPump 选择**前向欧拉法**。

## AirPump 字段与 SOTE 拟合 {#airpump}

SOTE 是标准条件下，送入空气中的氧转移到清水的比例。它随**单个曝气器的风量**和**浸没深度**而变。厂商提供现成的拟合系数时可直接输入；提供不同工况的效率表时可在 Dash 中拟合。

| 字段 | 含义和填法 |
| --- | --- |
| `SOTEa` | 效率曲线的系数 a。单个曝气器风量为 1 m³/h、深度为 1 m 时的效率，按小数填写，如 5% 填 `0.05`。 |
| `SOTEb` | 风量指数 b。深度固定时，单个曝气器风量加倍，效率乘以 $2^{-b}$。 |
| `SOTEc` | 深度指数 c。单个曝气器风量固定时，深度加倍，效率乘以 $2^c$。 |
| `θ` | 传氧系数的水温修正因子，填正数，无单位。新建 AirPump 预填 `1.024`。以 20 °C 为固定参考温度，每升高 1 °C，KLa 乘以一次 θ。填 `1` 可关闭这项修正。 |

新建 AirPump 的 a、b、c 初值为 `1, 0, 0`，这会使所有工况的 SOTE 都等于 100%。实际设备应填对应的曲线系数。在**接收 CSTR** 中，填写实际运行的曝气器数量 $N$ 和浸没深度 $H$（m）。两者均大于零时才有空气传氧。α 修正清水与工艺水的传氧系数，β 在淡水饱和模型下修正饱和溶解氧浓度。池内水温由 **Environment** 的 `T` 提供，缺省为 20 °C。[水温和饱和溶解氧的填写方法](./Edit.mdx#environment)

**练习一次拟合。** 打开 AirPump 详情的**拟合 SOTE 曲线**。每行填一个试验点，各列都要填正数，至少三行。下面三行是教学用数据，实际使用时可输入或通过 CSV 导入设备试验点。分别改变风量和深度，才能从数据中区分两个指数的影响。

| Qd：单个曝气器风量（m³/h） | Diffuser Depth：浸没深度（m） | SOTE：效率（%） |
| ---: | ---: | ---: |
| 1 | 2 | 10 |
| 4 | 2 | 5 |
| 4 | 4 | 10 |

点击曲线弹窗右上角的拟合按钮，系数会回填至泵详情，再点击**应用**。本例可得到约 `0.05, 0.5, 1`。**拟合表里 10% 填 10**，SIMPO 在内部换成 0.10。若 Flow 的总风量是 9,600 m³/d，100 个曝气器均匀供气，则 $Q_d=9600/(24\times100)=4$ m³/h。深度 4 m 时，$\mathrm{SOTE}=aQ_d^{-b}H^c=0.05\times4^{-0.5}\times4=0.10$，正好对应最后一个试验点。

## KLaPump 字段与多池共用 {#klapump}

| 字段或位置 | 含义和填法 |
| --- | --- |
| 泵详情的 `θ` | 正数，无单位，新建默认 `1`。若输入序列已是希望直接施加的 KLa，保留 1。若序列按固定水温标定，填对应的温度因子。 |
| 泵详情的 `TRef` | 输入 KLa 所对应的参考水温（°C），新建默认 `20`。若设备在 15 °C 标定，填 `15`。 |
| 连接上的 Flow | 填有限、非负的参考 KLa（d⁻¹）。在每个接收池，SIMPO 用该池水温计算实际值 $KLa_{tank}=KLa_{ref}\,\theta^{T-T_{ref}}$。 |
| 接收 CSTR 的饱和模型 | 决定传氧所趋近的溶解氧浓度。复现 BSM1 时选**恒定**，填 **8 mg O₂/L**。 |

一台 KLaPump 可以用同一序列连接多座 CSTR，各池获得完整参考值，再按各自水温修正。例如给两个池同一个 **100 d⁻¹**，设 `TRef = 15`、`θ = 1.024`。水温 15 °C 的池得到 100 d⁻¹，20 °C 的池得到约 112.59 d⁻¹。若多台 KLaPump 共用此序列，各泵的 TRef 必须一致。每个 CSTR 最多接收一条直接 KLa 连接；采用直接 KLa 的池须采用单一曝气方式，AirPump 可接到其他池。

### 按 BSM1 晴天开环填写 {#bsm1}

| From | Flow | Into | 序列数值 |
| --- | --- | --- | ---: |
| `KLaPump34` | `KLa_34` | `Tank3` | 240 d⁻¹ |
| `KLaPump34` | `KLa_34` | `Tank4` | 240 d⁻¹ |
| `KLaPump5` | `KLa_5` | `Tank5` | 84 d⁻¹ |

两台泵都填 `θ = 1` 和 `TRef = 20`。若某时刻 Tank5 的溶解氧为 2 mg/L，曝气单独贡献的浓度变化率为 $84\times(8-2)=504$ mg O₂/(L·d)。闭环案例由 Controller 调节 `KLa_5`。在 Assessment 中，输入 `KLa_5` 读取连接信号的有效值，输入 `Tank5.KLa` 则读取施加到该池的实际传氧系数，包含池温修正。[在 BSM1 案例中核对曝气连接和运行值](../../CaseStudy/BSM1/Setup.mdx#aeration)
