# 新建 DataSet

DataSet 用于保存 SIMPO Project 使用的测量数据和工艺流程。流程图由 DataSet
中的 Tanks 和 Connections 自动生成。

## 空白新建

创建空白 DataSet，编辑 Detail，并通过 `Parse` 保存后再用于计算。

- 添加必需的 Targets 和 Tanks。
- 有测量数据时，为 Tanks 和 Inflows 添加数据。
- 存在进流、回流、泵、出水或排泥时，添加 Flows 和 Connections。

## 随新建 Project 一起新建

创建 Project 时如果不指定 DataSet，SIMPO 会自动创建一个空白 DataSet。

## 从预设布局新建

预设布局会创建初始工艺结构。模板文件为空时，可以选择 BioModel，并将其
Components 作为 DataSet 的 Targets。

可选布局包括：

- `Batch`
- `Chemostat`
- `CAS`
- `CAS-Pump`
- `AO`
- `AO-Pump`
- `AAO`
- `AAO-Pump`
- `UCT (AAAO)`
- `UCT (AAAO)-Pump`

名称以 `-Pump` 结尾的布局包含曝气计算所需的 Pump。保存前请检查生成的
Targets、Tanks 和 Connections。

## 使用 AI 新建

在新建 DataSet 对话框中点击名称旁的 AI 按钮，选择可用模型并详细填写设计
条件。使用前请人工检查生成的 DataSet。AI 创建最长可能需要十分钟。
