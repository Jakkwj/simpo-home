# 已保存的平衡与反应分析

本参考解释已保存核算数据。读取、筛选和分页由执行适配提供；它们不会改变原始计算结果，也不重新运行求解器或积分。先复用摘要中的定义、单位和证据，只有缺少解释依据时才补读同次运行相关配置。

## 选择核算范围

- 核对项目、实际引擎、运行状态和结果时效。Balance 当前来自 SIM；不得把其他引擎的浓度序列当成已保存的 Balance。旧运行没有该分支表示不可用，不表示全零、没有异常或已闭合。
- 稳态以保存快照核算单位时间的收支；动态覆盖该次动态模拟的全部保存区间，以累计质量或对应指标量核算。组合模式不把此前稳态迭代时间计入动态积分。库存按区间两端实际质量计算，不能只对浓度相减而忽略体积。
- 默认顺序为 Composition、Component、Target，每类保留模型/运行原始顺序。空 Composition 行隐藏；缺少部分系数的非空行仍可能显示不完整。不能为隐藏或闭合而补零、删异常或修改系数。
- Target 来自保存的 Conversion。只有一个非零系数且其值为 1 时，它是该 Component 的恒等别名，即使名称或单位文本不同也不重复展示；用服务返回的别名信息说明去重，使用实际 Component 查询。单位文本可能仍需解释，不能据此另造一套数值。复合、缩放和非恒等 Target 保留并按 Component 贡献展开。
- 筛选使用返回的完整 dimension/key/tank 标识，不能从案例推断其他项目的组分数量、名称、池体或流量。无条目与数值为零、不可用与无异常是不同状态。

## 选择视图和读取证据

| 视图 | 用途和边界 |
| --- | --- |
| `summary` | 各核算项总输入/输出、差值、容差、已保存核算状态与显示状态；用于确定关注项 |
| `diagnostics` | 全局提醒和需关注项的原因、严重程度、对应差值；没有行不能忽略全局提醒 |
| `terms` | 进出水、反应、物理交换、约束、库存等收支贡献明细 |
| `tanks` | 同一核算项的反应产生、消耗、净值按池体汇总；不是每个池体完整水力/质量收支 |
| `reactions` | 按池体和 Reaction 展开的反应产生/消耗；用于解释 gross 产生与消耗 |
| `concentrations` | 单独分页的浓度异常证据，包括 Component、池体、类型及可用的时间/数值信息 |

先读取用户需要的摘要或异常，再展开相关项，不重复获取所有指标的所有反应。每次记录 scope、view、selection、单位和页范围。摘要的累计量已经来自整个保存区间；页范围只限制本次读取哪些行，不把一页摘要误称为局部时间积分。需要自行求和明细、声称检查了所有异常或全体指标时，遍历该视图全部分页。不得将同一笔流量的多级汇总重复相加。

摘要行的 `detail_availability` 分别标明 terms、tanks、reactions、concentrations 是否保存。所有明细视图都须检查 `balance.details_available`；为 false 时，`details_reason` 解释未保存的类别。未保存不等于已保存的空列表，不能把缺少明细解释为零贡献、无反应或无浓度异常。

## Mass Balance 与 Reaction Analysis

全厂完整收支把系统外边界的输入/输出、反应净值、物理交换、Constraint 和库存变化一起考虑；内部回流不重复计入全厂进出水。系统边界以保存记录为准，单池收支还需要相邻池传输，因此 `tanks` 的反应汇总不能替代它。

反应分析只统计反应产生和消耗，净值为产生减消耗。两侧无需相等；同一 Component 大量产生和消耗可能几乎抵消。反应图相邻节点只代表分类汇总，不证明分子的来源去向。完整收支通常按池体净反应列项；它与 gross 反应产生/消耗图不能直接逐条相加比较。投影后的同一池体/反应内先合并 Component 贡献再分正负，不把不同投影项的 gross 总量误认为 Target 的 gross 产生。

批式反应没有进水也可核算：初始库存 + 外部输入 + 净源 = 最终库存 + 外部输出 + 净汇。初始存在的 NO₃ 被消耗可由库存减少供给，不需要虚构进水。图中库存增加为汇、库存减少为源；这些是同一库存变化的两种表达，不与初末库存再次重复相加。

## Composition、Target 与守恒判断

- Composition 是按模型系数对 Component 做线性投影，不仅限于 N、P、S。ThOD、Charge 等可有负系数；负投影系数/有符号通量与负浓度不同，不能裁掉负系数或把它们全部判成异常。
- `reaction_invariant` 表示按所用系数投影后，各反应的化学计量净变化是否在判据内为零；它检查的是反应矩阵的性质，不是“本次模拟是否收支闭合”，也不是某次运行净反应量是否恰好为零。它为 false 时仍可通过显式计入反应项核算闭合。
- N 是否守恒取决于模型的氮含量、反应矩阵、边界、气体交换和缺项，不能从一个案例推广到所有模型。TSS 可因溶解/颗粒转化而变化；Charge、ThOD 的投影性质须核查真实定义、反应及物理项，不能要求它们天然都满足输入等于输出。
- Target 与 Component 使用同一套收支项，区别在于线性投影权重。非线性定义、缺系数、未解析表达式或数据不支持时，报告保存的限制，不擅自近似成线性映射。

## 水流、传质与 Constraint

- `water_input`、`water_output` 是跨全厂水流边界携带的组分/指标量，不是单纯水体积；单位以该核算项为准。排泥按实际外排边界计入，不把内回流当出水。
- `physical_input`、`physical_output` 来自模型已记录的物理交换，如曝气供氧、气液传质或气体排放。正负方向分源/汇；不能默认它们包含所有真实装置，也不能仅据名称认定全部是曝气。
- `constraint_input`、`constraint_output` 是施加浓度约束所需的补偿源/汇，可能从库存/其他项反推，不能当作已测量供氧量或真实泵入/排出量。`contains_inferred_constraint` 表示含反推的约束贡献。用收支残差反推出补偿，再得到闭合，不构成独立的模型守恒验证。
- O₂ 应结合进出水携带量、反应消耗/产生、物理供氧、Constraint 和库存核算。不把 Measured DO 当持续供氧，不在已有物理项之外再次添加同一供氧项。稳态/动态 Constraint 启用规则仍按主流程核对。

## 差值、容差与动态积分

保留 `assessment` 原值，并用 `display_assessment`、`severity` 和返回原因解释。只读查询成功与科学核算通过不同：异常行不等于命令失败；缺项/不支持也不能当作普通数值超限。

对于服务实际返回的总源/总汇，带符号残差为输入减输出；动态展示的绝对差值是其绝对值。相对差值通常以输入与输出之和为分母，而不是浓度、进水量或 gross 产生量；按返回定义解释零尺度/非有限值，不自行除零。闭合判据为：

```text
abs(residual) <= max(absolute_tolerance,
                     relative_tolerance * (total_input + total_output))
```

绝对容差与差值使用同一单位；相对容差是比例，例如 0.001 对应 0.1%。必须同时超过绝对及相对容差才属于此判据的超限。不能把四舍五入后的显示值重新判定状态。

动态超限表述为“累计收支核算差异超限”，同时报告绝对差值、相对差值、实际积分方法和保存采样点数。必要时给出对应容差及带符号残差，注明它不是浓度误差。提示：**该差异可能来自后处理积分、数值求解或收支项缺失，尚不能仅据此判定模拟错误。** 缺数据或非有限值时不能把无法判定解释为闭合。

积分基于保存的输出时间点，不是求解器内部每一步。真实方法以本次保存元数据为准：三次样条 `sampled_cubic_spline` 使用 not-a-knot；少量点可按实现降为线性或二次，正负贡献按曲线分段累计；旧结果仍可能是梯形 `sampled_trapezoidal` 或分段常数 `sampled_previous`。未知方法或缺少采样/分辨率时明确未知，不用当前默认设置冒充历史运行。三次样条可能改善近似但不保证闭合，也不应强制修正积分以等于库存差。

提高分辨率通常增加保存时间点，有助于积分精度，但不是误差必然单调下降的保证；求解容差控制数值解精度，两者不同。报告中的 `resolution_rate` 已经是百分数，例如 100 表示 100%，不能再乘 100。具体计算命令的输入单位由执行适配说明。只读分析不自动修改分辨率或重算。

## 提示和具体异常

- 全局采样提示和单个核算项差异提示相互独立。前者影响整次动态运行的采样解释，后者只针对所选项的收支差值；不要合并成同一种错误。
- `input_breakpoints_not_sampled` 说明保存的采样/输入变化覆盖检查未通过。某些版本只检查输入时间戳，Previous 还要求变化点两侧记录，恒定输入也可能触发；没有实际值变化证据时只能称“覆盖未确认”，不能断言输入发生跳变、采样漏掉跳变或模拟有误。不要仅凭该标记确定某段累计量必然不准确。
- 浓度异常按 `concentrations` 返回的 Component、池体、类型、首次/最小值及时间解释，区分负值、NaN、正无穷和负无穷。带符号投影或反应速率允许为负，不等同非物理浓度。旧结果未保存细节时明确无法定位，不编造数值/时间，不在分析中裁零或改写原结果。
- 净反应量由较大的产生与消耗相减得到时，较小积分差异也可能放大净收支的相对差值。说明实际绝对规模和单位；百分比大不等于浓度解出现同幅度误差，但也不能排除模型、数值或缺项问题。
- 需要解释差异来源时，检查相关项是否齐全、物理/约束项来源、异常浓度、输入变化与采样覆盖、实际积分及求解配置；未核实的原因只能列为可能性。不能为了给出原因而自动重算。

## 能回答和不能回答的来源问题

可以描述某组分在哪些池体/反应中累计产生或消耗，以及按系统边界离开的形式；不能把这些汇总解释为“某股进水中的氨氮最终有多少变成 NO₃、N₂ 或生物量”。这需要另行实现标签/来源追踪或其他明确归因模型，当前视图没有该能力。
